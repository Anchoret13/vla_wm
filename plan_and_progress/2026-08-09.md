## V7.4A — interface layer and content assertions

**Registered interface (primary).** For pooled state
`p = Pool(z_t^ℓ) = z.mean(dim=1)`:

```
c_t = (p − μ_train) / σ_train
```

with `μ_train` the uniform mean over the COMPLETE V7.4 policy-state
set (all real policy-anchor pools — grounded, model-eligible, and
abstention — plus all demo-rehearsal pools) and `σ_train` the scalar
population RMS of the centered pools over that same set. Both are
computed once from the frozen V7.4C checkpoint, saved in the run
lineage, and never recomputed after the first policy forward. The
flow boundary is unchanged: `v' = v + W_c c_t`, `W_c` bias-free
zero-init, trained jointly with stock-initialized `action_out_proj`;
everything else frozen. The constant-state control arm uses `c = 0`
(the centered analogue of the V7.3 global-mean arm).

**Registered fallback (only alternative).** One learned-query block:
a single trainable query attends over the LCWM's 4 state tokens
(single-head scaled dot-product, d=384), and the attended vector
replaces `p` in the same centering/normalization and the same
`W_c` boundary. No planner, no best-of-N, no deployment change.

**Frozen non-collapse thresholds** (dimensionless, σ_train = 1
units, computed over the complete anchor set, not one probe; reset
and order-only-shuffled variants are built per anchor with the V7.3D
order-only construction):

- T1 identity: median pairwise ‖c_i − c_j‖ over distinct real
  anchors ≥ 0.30;
- T2 history: ‖c_real − c_reset‖ ≥ 0.05 for ≥ 2/3 of anchors with
  decision index ≥ 5;
- T3 order: ‖c_real − c_shuffled‖ ≥ 0.05 for ≥ 1/3 of anchors with
  decision index ≥ 5;
- T4 paraphrase: median same-goal paraphrase distance ≤ 0.5 × the T1
  median (crossed-text anchors only);
- T5 goal separation: median compatible-alt-goal distance ≥ 1.5 ×
  median paraphrase distance (crossed-goal anchors only).

**Frozen decision rule.** The probe instrument runs twice:

1. **A-stage diagnostic** on the existing V7.3C LCWM checkpoint and
   V7.3 anchor set (instrument validation; the 2026-08-07 audit
   numbers are prior data and this run is report-only). If the
   centered POOLED interface fails T1 or T2 here, V7.4 commits to the
   fallback interface immediately — the pooled candidate is not
   retrained on V7.4C states.
2. **Binding gate before V7.4D** on the frozen V7.4C checkpoint over
   the complete V7.4 policy-state set. Failing the binding gate on
   the committed interface triggers the one registered fallback
   switch (if not already taken) and one re-run of the gate. A second
   failure halts V7.4 before policy training with status
   "state-content deficiency localized to the LCWM"; that is a
   result about V7.4C's state, not a license for an interface sweep.

**Training-time checks.** At policy step 50: over all scheduled
anchors, `Var(W_c c) / (‖mean(W_c c)‖² + Var(W_c c)) ≥ 0.5`
(V7.3's measured value was ≈ 1e-8). Failure halts that policy run
once, switches to the fallback if untaken, and restarts; otherwise
halts V7.4D. Final-step post-projection variation is recorded and
named in interpretation but does not gate V7.4E: behavior remains
the endpoint.

## V7.5 Stage 0 EXECUTED — recurrence gain measurement
(2026-08-09; `2026-08-09_v075_recurrence_diag_r1/recurrence_gain.json`;
`scripts/diag_v075_recurrence.py`; CPU, seed 0, tensor-only, 15 anchors
from the frozen V7.3C checkpoint and the A-stage probe state cache.)

Structure under test — `lcwm/v06_model.py::V06State.update`:

```
c     = Anchor(h)                          # observation + language
z_bar = T(z_prev, E_a(a))                  # history channel
state = LayerNorm(c + beta * tanh(R(c, z_bar))),    beta = 0.25
```

**Stated approximation.** `h` is unrecoverable (the h-caches are
retired), so `Anchor(h)` cannot be recomputed and `c` is stood in for
by the cached real token states. This is valid exactly in the regime
the A-stage established — the history term does not move the state, so
`state ~ LayerNorm(c)` — and every reported quantity is stable across
all 15 anchors used as `c`. The exact online quantity is produced later
by the V7.5C per-epoch history-dependence readout.

**Measured — the history path fails at two independent sites.**

| quantity | median |
|---|---|
| `max abs(R_pre)` (pre-tanh) | **28.77** |
| `frac(abs(R_pre) > 1)` | **1.000** (all 15 anchors) |
| `norm(attended) / norm(c)` | 5.19 |
| d(`attended`) vs other anchor's history | **4.78e-06** |
| d(`attended`) vs fully random history | 5.22e-03 |
| output gain vs other anchor's history | **1.82e-10** |
| output gain vs reset history | **0.0** (bit-identical) |
| output gain vs random history | 3.63e-08 |
| output gain vs a different observation | 2.26e-03 |
| **observation / history gain ratio** | **1.24e+07** |

1. **Upstream — the attention is starved of contrast, not of
   magnitude.** `attended` is 5.19x larger than `c`, so history is not
   quantitatively small; it is nearly *constant*. Swapping in another
   anchor's history moves `attended` by 4.8e-06 relative; a fully
   random history moves it by 5.2e-03. The cause is the same
   common-mode degeneracy the policy interface had: raw `z` states are
   nearly identical to one another, so `proj(z_bar)` gives the
   attention near-identical keys and values. Centering repaired the
   *readout* in V7.4A; the recurrence consumes **raw** `z` and was
   never repaired.
2. **Downstream — the tanh is fully saturated.** `abs(R_pre)` exceeds 1
   at **100% of units at every anchor** (median max 28.77). `tanh` is
   pinned at +/-1, so the surviving 4.8e-06 of upstream variation is
   annihilated: the state receives a history term worth 24% of
   `norm(c)` that is bit-identical across history variants. Saturation
   also means `dtanh ~ 0`, so the history path receives essentially no
   gradient — it is frozen, not merely unused.

**Scalar fixes are measured to be insufficient.** Raising `beta`
across {0.25, 1, 4, 16, 64, 256} leaves the gain at 1e-10..1e-9;
scaling `R.out` across {1, 4, 16, 64, 256} drives it to exactly 0.
Both scale a *constant* saturated vector. The mechanical sub-choice
registered in the approved plan therefore returns
**`desaturate_and_reinject__scalar_fixes_insufficient`**, and the
"raise beta / drop zero-init" branch is retired unused.

*Recorded process note.* The first revision of this script's verdict
rule read the beta sweep's 1.8e-10 -> 1.0e-9 step as a linear-regime
response and emitted `raise_beta_and_drop_zero_init`. Both numbers are
floating-point noise. The rule now requires a gain to clear a
registered usable threshold (1e-4) before any sweep counts as
recovering it, and the failure sites are tested independently. The
wrong verdict never left the working tree.

## V7.5 Stage 1 — the registered correction (three coupled parts)

Stage 0 makes the ordering non-optional: gradient pressure alone cannot
act through a saturated bound, so the architecture is repaired first
and the objective supplies the reason to use it.

1. **Desaturate the history bound.** Normalize `R`'s output before the
   bound so the path operates in its responsive regime and passes
   gradient. Replaces an unconditioned `tanh` on a magnitude-29 input.
2. **Re-inject with contrast.** The recurrent state consumes a
   **centered** `z_bar` (the V7.4A repair applied where it was never
   applied), so near-degenerate raw states become separable attention
   keys. Statistics frozen and saved in the run lineage exactly as the
   policy-side centering is.
3. **Short latent rollout (framework_design.md 3.2).** The state
   predicts k steps ahead with **no intervening observation**, so the
   anchor is unavailable for steps 2..k and the only way to reduce the
   loss is to carry information in `z`. The present closure term is
   3.1 one-step self-prediction on a detached target, which any
   observation-anchored state satisfies trivially. `k` is frozen before
   training.

Parts 1 and 2 are architecture and cannot be "won" by the model; part 3
is the only new objective term. No sweep over any of the three.

### Review round — six defects, four caught before execution

1. **Detached rollout starts** (pre-execution). The TBPTT window bound
   alone still lands ON the detach boundary whenever the anchor's
   decision index is a multiple of TBPTT, so those rollouts would
   train only `T` and the predictor and apply zero pressure to the
   recurrent state — defeating the entire point of the term. Fixed
   with an explicit `requires_grad` filter; asserted by the contract
   test.
2. **`sigma` is inert in the rollout distance** (pre-execution).
   `latent_distance(..., "cosine")` is scale-invariant, so dividing
   both sides by `sigma` does nothing; only the mean subtraction acts.
   No functional change — the mean subtraction is the part that
   matters — but the code and manifest wording claimed more than the
   term does and were corrected.
3. **Conditional swallowed a log field** (pre-execution). A
   `f"..." if roll_true else ""` inside an implicit string
   concatenation binds across the following literal, silently dropping
   `sigma` from every readout line. Fixed.
4. **Dev split leaked into the centering statistics** (pre-execution).
   `hist_center.observe()` fires on every `V075State.update()`, and
   `online_readouts` is `@torch.no_grad()` but NOT `eval()`, so every
   per-epoch readout was folding dev states into the statistics the
   training objective is normalized by. Fixed by `eval()`/restore
   around the readouts; verified directly (train-mode observes,
   eval-mode does not).
5. **Calibration set 17 != 20** (execution). The inherited selector
   required a DISTINCT anchor per microbatch, which silently caps a
   task at its anchor count — and t4 has ONE train anchor. `inv` would
   have missed its >= 10 quota next. Distinct anchors are still
   preferred, with a fallback to distinct QUERIES of an already-used
   anchor; per-task anchor diversity is recorded in
   `gradient_balance.json`. Now 20 microbatches, `inv` 11,
   rollout-supported 17.
6. **In-place statistic updates broke backward** (execution).
   `observe()` mutates `mu`/`sigma` in place while `(z - mu) / sigma`
   saves the divisor for backward; a recurrent unroll observes once
   per decision, so backward raised "variable needed for gradient
   computation has been modified by an inplace operation". This is the
   SAME failure class as the V7.3D in-place stock-head swap. Fixed
   with detached clones snapshotted before observing (which also makes
   a step's normalization independent of its own contribution), plus a
   7-step-unroll backward regression test.

Rollout support: 20 of 24 train anchors have decision index >= 3; the
four without are t3's three d=2 anchors and one t5 d=2 anchor. The
deepest anchors (65, 48, 37, 26) are exactly where history has the
most to carry.
