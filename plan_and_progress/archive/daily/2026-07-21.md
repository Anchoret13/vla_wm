## PRE-REGISTERED: §11.2 input-arm sweep (Candidate-A instrument)

Question: which frozen input arm — {siglip-only, canonical-LL-only, fused} —
best supports a LEARNABLE task-conditioned predictive state, judged by learning
behavior (v0.2 §11.2), not static decodability?

Instrument (fixed across arms): minimal Candidate A. Oracle TASKID embedding
(d_e=256); Carry = 2 cross-attn blocks, M=4, d_z=384, FiLM(e_task) on queries;
Transition = 4-block transformer over [Z | action-block emb | e_task emb];
heads (NO e_task bypass, contract §1): predicate bits (masked BCE), progress,
proprio anchor. Self-prediction: BYOL-style EMA target chain, cos-dist on
LayerNorm'd carry; burn-in 2, rollout k≤4, seq len 8 decision steps.
Data: seq_libero_10, splits by demo per task 7/1/2 (train/val/test).

Diagnostics (test demos, 2 seeds): k=1..4 rollout cos-dist; trivial-copy
baseline (Ẑ_{t+1}=Z_t); action-shuffle + zero-action controls; task-shuffle
(SHUFFLED τ) → Δ predicted predicates/progress + carry divergence; predicate
F1 / progress R² under true τ; effective rank (SVD entropy), per-dim std,
cos-to-init; learning curves.

Provisional promotion rule (an arm is "usable"): (a) k=1 prediction beats
trivial-copy by >20% rel; (b) action-shuffle degrades k=1 by >20% rel
(action-conditioned, not copying); (c) predicate F1(true τ) > 0.8 AND
task-shuffle produces nonzero predicted-future change (report magnitude);
(d) effective rank ≥ 96 (= M·d_z/16, anti-collapse); stable across both seeds.
Failing arms are reported as-is; if ALL fail, the instrument (not the features)
is investigated first (capacity/objective), per honest-reporting rule.

## PRE-REGISTERED: rank-criterion instrument investigation

Q1 reference ranks (was 96 ever realistic?): effective rank of (a) the EMA
target carries themselves, (b) the raw input tokens (mean-pooled to 1536-d via
random projection), on the same test set — the data's own rank budget.
Q2 ablations (siglip arm, seed 0, 30 epochs each): (i) anchor-head weights
halved (W_PRED/W_PROG/W_Q ×0.5); (ii) + VICReg-lite variance term on the carry
(std target 1.0, weight 0.1). Criterion: an ablation "fixes the instrument" iff
eff-rank ≥ the reference rank of (a) × 0.5 AND a/b/c criteria all still pass
(margin>0.2, act-sens>0.2, F1>0.8). If neither fixes it, the rank threshold is
re-derived from the Q1 references and the sweep verdicts are re-issued against
the corrected threshold — with the change documented, not silently applied.

## Rank investigation RESULT + input-arm DECISION

Q1 references: raw-token rank budget **36.5**, EMA-target chain **16.7** — the
96 bar was miscalibrated fantasy (documented, threshold re-derived per the
pre-registered clause: ≥ 0.5 × raw reference = **18.3**, both seeds).
Q2: anchor×0.5 alone no effect (16.1); **+var-reg 0.1 lifts rank at zero cost**
(actsen 1.16/0.96, F1 0.99, R² 0.93/0.94).

Final verdicts (corrected rule, both seeds): **siglip + var-reg PASSES all
criteria** (margin 0.69, actsen 0.96–1.16, F1 0.99, rank 18.9/19.3 ≥ 18.3).
real_ll would pass rank but barely passes actsen; fused fails actsen.
