## Feature-shift visualization (tap-source [DEC] diagnostics)

`scripts/viz_feature_shift.py` → `results/viz/feature_shift/`. On frames from a
libero_10 t0 rollout (t = 0 / 80 / 160), compared last-layer image-token features on
the SAME frame under three prompts: **real** instruction, **const** tap prompt
("do the task"), **alt** = a different task's instruction (content-specificity control).
Outputs: per-camera 16×16 cos-dist heatmaps overlaid on frames, joint-PCA token
displacement, per-token histograms, `summary.json`.

### Findings (revise yesterday's alarm)

1. **Heavy-tailed, not uniform**: most tokens are ~prompt-invariant (mode < 0.05
   cos dist); the 0.20 mean is driven by a shifted minority (tail to 1.2+).
   Language mixing hammers a few tokens, it does not rewrite the scene encoding.
2. **Content-agnostic magnitude**: alt-instruction shift ≈ const shift at every
   timestep (e.g. t0 agentview 0.243 vs 0.227); shift-map spatial corr const-vs-alt
   0.38–0.69. Two *real but different* instructions do not differ more than
   real-vs-const → the perturbation is "any prompt change", not instruction content.
3. **Speckled, not object-localized**: hot tokens scatter over background/arm/objects,
   not concentrated on task-relevant objects. PCA shows a prompt-shared manifold
   holding most tokens; the jumpers between clusters are the heavy tail
   (register/attention-sink-like, likely not object-semantic carriers).

### [DEC] update — tap source

Constant-prompt **last-layer** is now the FAVORED tap (risk much smaller than the

## §11.1 same-frame prompt controls — RESULT (commit `TBD`, results/feature_controls/)

Same frames (t=0/80/160 of a t0 rollout), seven prompts: canonical t0, 3 paraphrases,
t1 (same LIVING_ROOM_SCENE2, different target objects), t2 (unrelated), constant.

| vs canonical t0 | mean cos dist (t0/80/160) | tokens >0.3 (t0) |
|---|---|---|
| paraphrases ×3 | **0.013–0.063** (p50 ~0.005) | 1–4% |
| t1 same-scene | **0.403 / 0.197 / 0.414** (largest) | 40% |
| t2 unrelated | 0.279 / 0.139 / 0.320 | 25% |
| const | 0.271 / 0.117 / 0.299 | 25% |

Findings (REVERSES yesterday's "content-agnostic" read — which was an artifact of
having only one alt-task control):

1. **Paraphrase invariance is already in the frozen backbone**: same task, different
   wording moves features 7–10× less than any task change; residual paraphrase
   directions ~orthogonal to task-change directions (cos 0.05–0.3).
2. **Features are most sensitive to the decision-relevant distinction**: t1 (same
   scene, only target objects change) shifts MORE than a fully unrelated task.
   The last layer encodes which objects matter → **H_task stream carries real value**.
3. **const ≈ t2 in magnitude AND direction** (dir cos 0.57–0.73, highest pair):
   constant prompt ≈ removing task info → supports const last-layer as an H_world
   candidate (task-neutralized view).
4. δ(t1) shares ~0.5 direction with δ(const)/δ(t2) (generic component) plus a large
   non-shared task-specific component. Whether it localizes on target objects →
   pending segmentation masks (in progress).
5. SigLIP pre-trunk prompt-invariance maxdev = exactly 0.0 (sanity + determinism).
6. Corrected joint-PCA (shared centering, EV 0.59+0.10): conditions share one
   manifold; t1 re-codes a token subset (large jumps), rest stay put.

Framework implication: §0's required representation behavior (paraphrase→same,
task→different-and-decision-relevant) already holds at the frozen-feature level;
the 10-way task normalizer has strong backbone support.
