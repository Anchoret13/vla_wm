# 2026-07-29 — Close the model-to-policy loop before architecture changes

**Status note, superseded after 2026-07-30.** H0–H7 are complete. This file is
frozen preregistration and execution history: no unchecked item below is a
current instruction. H7 produced no promotable v0.5 arm, and the executed
model did not instantiate the registered language-conditioned predictive
state. Its immediate successor was [LC-Flow v0.6](2026-07-30.md); the only
active queue is [the v0.6 execution repair](2026-07-31.md).

## Decision

The current architecture should not be expanded before the first complete
model-to-policy evaluation. `LCState` already provides an action-conditioned
recurrent belief, an explicit controlled transition \(T(z_t,a_t)\), and a
direct path from the learned state to the deployed policy.

The immediate objective remains unchanged:

```text
learned recurrent predictive state
        → action-learning signal
        → changed π0.5 policy
        → improved full-prompt N=1 success
```

The current evidence sets two experimental priorities.

1. The existing `v0.4-e2e-v1` path must first be completed as a fixed
   vertical-slice baseline. The current results do not yet evaluate the main
   hypothesis because no P4 world model has produced a policy checkpoint.
2. The next strong baseline is a simpler recurrent belief-conditioned policy
   trained from reliable action supervision, without model-generated candidate
   ranking. This tests whether recurrence and direct policy conditioning alone
   explain any gain before additional representation engineering.

Do not add a new feature encoder at this stage. π0.5 already provides both
task-aware late prefix features and earlier visual features that can be used if
the current representation must be revised.

|---|---|
| recurrent state and π0.5 adapter wiring | mechanically validated |
| P2 recurrent self-prediction | did not pass Gate A; mean-next remained stronger on dev |
| full chain cache | complete |

| deployed-policy evidence | old one-seed 0/0 tie; not a test of the current mainline |

The three current risks are:

1. **Self-referential latent targets.** The late prefix and its EMA copy may
   admit a slowly varying, low-rank solution that does not preserve
   action-dependent future differences.
2. **Low-bandwidth policy conditioning.** Four latent tokens are mean-pooled
   into one global AdaRMS bias, which may be insufficient for phase- or
   action-token-specific corrections.
3. **Late-stage support.** The 207 decisions are highly correlated within five
   chain trajectories, and successful final-stage continuation has weak
   support. Candidate ranking may therefore be dominated by the manually
   specified \(\Delta\Phi\) term rather than learned continuation value.

These are failure hypotheses to localize after the first closed-loop run, not
reasons to delay that run.

Do not introduce belief tokens before testing the less invasive PEFT path.

## C2 — If actions change but model scoring is ineffective: revise the state

Build `LC-Flow v0.5` using π0.5-native feature factorization:

- physical belief tokens updated from early π0.5/SigLIP visual features,
  proprioception, and executed actions;
- task/progress belief tokens updated from the physical belief, late
  PaliGemma prefix features, and language;
- two physical and two task tokens initially, preserving the current total
  latent-token count;
- stop-gradient next early-visual/proprioceptive/effect targets in addition to,
  rather than only, the EMA recurrent latent target;
- policy access to both physical and task tokens.

The intended factorization is:

\[
\bar w_t=T_w(w_{t-1},a_{t-1}), \qquad
w_t=U_w(\bar w_t,V_t^{\mathrm{early}},q_t),
\]

\[
g_t=U_g(g_{t-1},w_t,H_t^{\mathrm{late}},l).
\]

Here \(w_t\) represents action-relevant physical state, while \(g_t\)
represents task-relative progress. Language need not alter physical dynamics;
it determines which physical distinctions are relevant to the task-conditioned
state and policy.

# Active supersession — matched attribution and long-horizon performance

## First-principle interpretation

Phase I is a real model-to-policy existence result:

```text
trained WM
    → selected policy targets
    → changed deployed policy
    → one full Chain3 completion
```

It is not yet evidence that learned dynamics caused the improvement. Three
facts set the next action items:

1. with three fresh π0.5 candidates and one exchangeable stock sample, the
   null probability that a fresh candidate scores above stock is approximately
   \(3/4=75\%\); the observed positive-teacher fraction is `73.4%`, so that
   fraction alone is not evidence of useful ranking;
2. selected advantages are driven by \(\hat V_{\mathrm{next}}\), while every
   late-chain \(V^{\pi_0}\) training target is zero; the score is therefore an
   off-support extrapolation that must be tested through a matched policy
   control;
3. the scalar `1 + clip(A, 0, 1)` weight was normalized by its own
   `weight_sum` for batch size one. Phase I is accurately described as
   **WM-selected, uniformly weighted teacher finetuning**, not
   advantage-weighted finetuning.

The earlier recommendation to fold seed 1078 into \(V^{\pi_0}\) training is
withdrawn. That trajectory was generated by `v0.4-e2e-v1`, so its return has
policy provenance \(\pi_{\mathrm{LC}}\), not \(\pi_0\). It is also a development
evaluation trajectory. If it is ever used for training, seed 1078 and the
current five-seed panel must be retired from subsequent evaluation and replaced
by a newly registered held-out panel.

The active objective is now:

```text
Does WM-selected policy training beat a matched score-blind selection control?
        ↓
Does that difference survive 700/900/990-step full-prompt N=1 tasks?
```

The previous immediate `B0/B1 → C3-lite` route is superseded by the queue below.

### Benchmark provenance correction

The target discussed in this project is the **publicly specified
LIBERO-LoHo benchmark**, introduced by H-WM as a five-task, 5–7-step
long-horizon modification derived from LIBERO
([arXiv:2602.11291](https://arxiv.org/abs/2602.11291)). It is not a benchmark
invented by this project. It is also distinct from the original public
`LIBERO-LONG` suite whose code name is `libero_10`.

The concrete `chain3_lr2/chain4_lr2/chain5_lr2` files used so far are a local
development curriculum derived from that public construction, not a subset
of the published five tasks:

- local Chain3 is soup + sauce + cream cheese → basket;
- local Chain4 adds butter;
- local Chain5 adds milk;
- public LIBERO-LoHo instead defines five separate 5/6/6/6/7-step tasks over
  basket, tray, and cabinet interactions.

Therefore the completed 700/900/990-step rollouts are genuine long-horizon
policy evidence, but they must be labeled **LIBERO-LoHo-derived development
curriculum results**. They are not direct public-benchmark numbers and cannot
be compared numerically with the H-WM table until the concrete task and
evaluation protocols are aligned.

## H7.3 — Train one fixed `LC-Flow v0.5-anchored`

The old free recurrent path accumulated prediction error and regressed on
Chain5. Removing history entirely would avoid that failure but would also stop
testing the project's main idea. The v0.5 state therefore keeps action-history
memory as a bounded correction to a state re-anchored by the real observation
at every policy decision.

### State

Construct a language-independent physical anchor and a task-conditioned
anchor from the same real π0.5 prompt pass:

\[
\begin{aligned}
c_t^w &= C_w(H_t^{\mathrm{early}},q_t),\\
c_t^{g,\ell} &= C_g(H_t^{\mathrm{late},\ell},q_t).
\end{aligned}
\]

Propagate action-conditioned priors and correct them with bounded residuals:

\[
\begin{aligned}
\bar w_t
  &= T_w(w_{t-1},E_a(a_{t-1})),\\
w_t
  &= \operatorname{LN}\!\left(
     c_t^w + 0.25\tanh R_w(c_t^w,\bar w_t)
     \right),\\
\bar g_t^\ell
  &= T_g(g_{t-1}^\ell,w_t,E_a(a_{t-1})),\\
g_t^\ell
  &= \operatorname{LN}\!\left(
     c_t^{g,\ell}
     +0.25\tanh R_g(c_t^{g,\ell},\bar g_t^\ell,w_t)
     \right).
\end{aligned}
\]

Zero-initialize the output layers of \(R_w,R_g\). At initialization the
anchored recurrent state is exactly the normalized current-observation anchor;
history can be learned, but it cannot replace the current observation or drift
without a bounded correction.

The two registered interfaces run the exact same modules and parameters:

\[
b_t^{\mathrm{reset}}
=
\operatorname{Update}
\left(
c_t^w,c_t^{g,\ell};
w_\varnothing,g_\varnothing,a_\varnothing
\right),
\qquad
b_t^{\mathrm{recurrent}}
=
\operatorname{Update}
\left(
c_t^w,c_t^{g,\ell};
w_{t-1},g_{t-1}^\ell,a_{t-1}
\right).
\]

`reset` resets the recurrent carry and previous action to registered null
values at every policy decision; `recurrent` carries the real visual-action
history across decisions. This is the only interface difference. Both use the
same token shape, current-observation anchors, residual modules, parameter
count, and zero-initialized π0.5 AdaRMS adapter. Language enters only through
the real prompt-conditioned feature, not through oracle `task_id` or a second
task-embedding bypass. Same-goal paraphrases should agree in \(g_t^\ell\);
compatible different goals may differ there; physical predictions from
\(w_t\) must remain shared.

### Candidate prediction and fixed first-run objective

For every candidate action, transition the posterior state before decoding
physical effects, next public-subgoal bits, damage, reward, terminal success,
and \(G^{\pi_0}_{100,i}\). Train:

- [ ] current-state grounding and action-conditioned next-outcome prediction
  on ordinary sequential windows plus the public sibling branches;
- [ ] absolute physical targets and within-snapshot centered action effects;
- [ ] task-relative subgoal, damage, reward, success, and continuation-return
  heads on the crossed language relabels;
- [ ] next-posterior prediction as an auxiliary closure loss, not the primary
  objective or a policy-launch gate;
- [ ] same-goal paraphrase consistency for task state and shared-physics
  consistency across compatible goals;
- [ ] source-balanced standard-LIBERO demonstration rehearsal.

Freeze π0.5 during world-model training. Run exactly one architecture, seed 0,
and one pre-registered training budget. Do not sweep latent dimension, residual
bound, loss weights, EMA settings, or seeds before closed-loop evaluation.

**Launch checks:** finite two-step mixed-data smoke, nonzero transition
gradients from the grounded heads, strict checkpoint reload, reset-mode
stock-policy parity with a zero policy adapter, and bounded state under a
1,000-step synthetic rollout. Grounded dev losses and latent diagnostics are
recorded, but none is allowed to delay the first policy finetuning job.

#### What the collected labels actually identify

The headline `70/160 dQ_public > 0` is not action-ranking support. It counts a
branch as positive relative to the snapshot before the subsequent stock
continuation. The relevant support for ranking is variation among sibling
actions at the same snapshot:

| grounded quantity | observed support |
|---|---:|
| 10-action subgoal/reward sibling variance | 0/40 groups |
| 100-action continuation-Q sibling variance | 7/40 groups |
| continuation-Q variance in the train split | 3/20 groups |
| groups with any non-stock Q above candidate 0 | 3/40 |
| non-stock branches above / below candidate 0 | 6 / 6 of 120 |
| terminal-success branches | 0/160 |
| negative `dQ_public` branches | 0/160 |

Three additional facts explain this:

1. Every one of the 20 `persistent_failure` snapshots is decision 4
   (`t=40`). The selector called an unchanged first-unresolved subgoal over
   five decisions a failure, although a normal first-object approach often
   lasts that long. Overall 32/40 snapshots still have subgoal 0 as their
   first unresolved phase. Train-split sibling object-outcome dispersion
   exceeds 1 mm in only 5/20 groups.
2. Continuation sampling uses a different random stream for each sibling
   (`cand * 10_000`). With one rollout per candidate, the seven varying
   continuation-Q groups mix the first-ten action effect with continuation
   policy noise; they are not clean controlled effects.
3. `SubgoalTracker.completed` is monotone. A placement or fixture state that
   is later invalidated remains credited in Q, so all 160 `dQ_public` labels
   are nonnegative and the collected records contain no actual damage label.
   This omits the preservation behavior that matters for long-horizon SR.

The policy-teacher manifest also does not extend the grounded support. Its 200
decision states come from the same source rollouts, but their exact
intersection with the 40 executed snapshot decisions is **0/200**. The frozen
WM therefore extrapolates action scores at every teacher state.

#### Why the teacher statistic was misleading

The `155/200 = 77.5%` non-stock selection rate is approximately the null
expectation. With four exchangeable continuous π0.5 samples, an uninformative
scorer chooses one of candidates 1–3 rather than candidate 0 with probability
`3/4 = 75%`. The observed count is only five selections above that expectation
(about 0.82 binomial standard deviations).

On the 20 held-out grounded groups, the frozen r1 checkpoint has:

- absolute continuation-value RMSE `0.1436 Q`;
- within-sibling centered RMSE `0.0348`;
- centered RMSE `0.0778` on the four variance-bearing dev groups;
- median teacher advantage only `0.00234`.

Thus the ranking-relevant error is approximately 15–33 times the median margin,
yet H7.4 selects any non-stock candidate whose predicted score exceeds
candidate 0 by an arbitrarily small positive amount. On the grounded groups,
the frozen scorer's argmax gives one improvement, one regression, and 18 ties
in train; dev has the same 1/1/18 count. The stable reset result
`WM ≈ random` is the expected behavioral consequence.

#### The implementation did not instantiate the registered LC predictive state

The repaired r1 model made task heads action-sensitive by concatenating a
language-independent physical prior:

\[
w_{t+1}^{(i)} = T_w(w_t,a_i),
\qquad
\hat y_i = R(c_t^\ell,g_t^\ell,w_{t+1}^{(i)}).
\]

It never transitions the candidate-conditioned task state
`g_t^\ell`. Candidate scoring is therefore a language-conditioned readout over
a physical action prior, not

\[
z_t^\ell
\;\xrightarrow{\,T_\ell(\cdot,a_i)\,}\;
z_{t+1}^{\ell,i}
\;\xrightarrow{\,R_\ell\,}\;
\hat y_{t+1}^{\ell,i}.
\]

Other registered components were absent or explicitly scoped out:

- the current-observation anchored `0.25 tanh` residual update was replaced by
  an unconstrained CrossUpdate; policy gates do not bound recurrent state;
- compatible-goal features were cached for T1↔T5, but no compatible-goal
  labels or loss consumed them; atomic goal relabels were not collected;
- paraphrases received state MSE only, not the registered task-head agreement;
- no next-posterior closure, multi-step latent rollout, centered sibling loss,
  damage head, success head, or within-sibling ranking loss was trained;
- sequential demo task heads read posterior `c_{t+1},g_{t+1}` after observing
  the next frame, whereas branch heads read current `c_t,g_t` plus a physical
  prior; these paths do not share one predictive-state semantics;
- `TBPTT=16` detaches once at `T-16`, producing two graph segments rather than
  truncating every 16 transitions.

The deployed policy interface also bypassed the intended memory mechanism.
`W_c(c_t)` is ungated and dominates the bias. Across manifest states, using
the same trained adapter with carried versus reset state changes the bias by
only 0.015–0.046%; all learned memory gates remain approximately `1e-3`.
Reset and recurrent arms, however, were optimized as separate adapters. They
already produce different actions at decision 0, before any history exists.
The `recurrent_wm Q=0.070` arm is therefore an independent-adapter optimization
collapse, consistent with its rising epoch-3/4 losses, not evidence that
history is harmful. The near-tied random arms show that history did not obtain
meaningful policy coupling in this implementation; they do not establish that
useful history is absent.

> H7 establishes that the implemented combination of a readout-style
> action scorer, nearly non-identifying monotone continuation-Q labels,
> zero-margin hard teacher selection, and independently optimized AdaRMS
> adapters does not improve the specification-based public-LoHo development
> panel. It does not test the registered anchored LC predictive transition,
> crossed task-identifier supervision, multi-step outcome sufficiency, or a
> clean same-policy reset-versus-carry history contrast.

Do not spend more seeds on r1 and do not run its sealed confirmation. Preserve
the artifacts and 150 episodes as the implementation-negative reference.

#### R2.2 — Implement the model actually described by the formulation

For every candidate and language condition, compute:

\[
\begin{aligned}
w_{t+1}^{(i)} &= T_w(w_t,a_i),\\
g_{t+1}^{\ell,i} &= T_g(g_t^\ell,w_{t+1}^{(i)},a_i),\\
\hat y_{t+1}^{\ell,i} &= R_\ell(w_{t+1}^{(i)},g_{t+1}^{\ell,i}).
\end{aligned}
\]

- [ ] Implement the registered observation-anchor plus zero-initialized,
  `0.25 tanh`-bounded residual for both physical and task state.
- [ ] Decode physical targets from `w_{t+1}^{(i)}` and task-relative
  predicate/progress/reward/success targets from the transitioned
  `g_{t+1}^{\ell,i}`; no current-state task bypass may answer the candidate
  outcome alone.
- [ ] Align transitioned states with the re-encoded branch-after posterior
  under the same language. Add two-/multi-block rollout targets from replayed
  sequential windows rather than replacing long-horizon prediction with one
  scalar 100-step head.
- [ ] Enforce paraphrase agreement and shared physical predictions across
  instructions while supervising compatible different goals with their own
  task-relative outcomes.
- [ ] Correct TBPTT and report source-disjoint dev outcome/controlled-effect
  losses. These are training readouts, not policy-launch gates.

- [ ] Select a non-stock teacher only when its calibrated lower-confidence
