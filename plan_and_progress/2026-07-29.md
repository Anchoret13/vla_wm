# 2026-07-29 â€” Close the model-to-policy loop before architecture changes

## Decision

The current architecture should not be expanded before the first complete
model-to-policy evaluation. `LCState` already provides an action-conditioned
recurrent belief, an explicit controlled transition \(T(z_t,a_t)\), and a
direct path from the learned state to the deployed policy.

The immediate objective remains unchanged:

```text
learned recurrent predictive state
        â†’ action-learning signal
        â†’ changed Ï€0.5 policy
        â†’ improved full-prompt N=1 success
```

The current evidence sets two experimental priorities.

1. The existing `v0.4-e2e-v1` path must first be completed as a fixed
   vertical-slice baseline. The current results do not yet evaluate the main
   hypothesis because no P4 world model has produced a policy checkpoint.
2. The next strong baseline is a simpler recurrent belief-conditioned policy
   trained from reliable action supervision, without model-generated candidate
   ranking. This tests whether recurrence and direct policy conditioning alone
   explain any gain before additional representation engineering.

Do not add a new feature encoder at this stage. Ï€0.5 already provides both
task-aware late prefix features and earlier visual features that can be used if
the current representation must be revised.

---

## Current evidence

| item | current interpretation |
|---|---|
| recurrent state and Ï€0.5 adapter wiring | mechanically validated |
| P2 recurrent self-prediction | did not pass Gate A; mean-next remained stronger on dev |
| full chain cache | complete |
| actionable late-chain train decisions | 207, but from only five train chain sources |
| P4 world-model checkpoint | none |
| model-generated teacher | none |
| new policy checkpoint | none |
| deployed-policy evidence | old one-seed 0/0 tie; not a test of the current mainline |

The three current risks are:

1. **Self-referential latent targets.** The late prefix and its EMA copy may
   admit a slowly varying, low-rank solution that does not preserve
   action-dependent future differences.
2. **Low-bandwidth policy conditioning.** Four latent tokens are mean-pooled
   into one global AdaRMS bias, which may be insufficient for phase- or
   action-token-specific corrections.
3. **Late-stage support.** The 207 decisions are highly correlated within five
   chain trajectories, and successful final-stage continuation has weak
   support. Candidate ranking may therefore be dominated by the manually
   specified \(\Delta\Phi\) term rather than learned continuation value.

These are failure hypotheses to localize after the first closed-loop run, not
reasons to delay that run.

# Phase II â€” Test the simpler recurrent-policy explanation

- [ ] Use only reliable expert or observed positive-branch action targets.

- [ ] Match the policy capacity, optimizer budget, rehearsal data, and
  evaluation protocol of the Phase-I policy arm.
- [ ] Evaluate on the same paired five-seed full-prompt `N=1` protocol.

## B1 â€” Add one matched recurrence control

- [ ] Replace the recurrent history with a current-observation-only state while
  preserving the state dimension, policy adapter, trainable parameter count,
  action supervision, and training budget.

The first comparison is therefore:

```text
stock Ï€0.5
vs current-observation policy adaptation
vs recurrent belief-conditioned policy adaptation
vs model-guided recurrent policy adaptation
```

Interpretation:

| result | supported conclusion |
|---|---|
| recurrent belief beats current observation, but model guidance does not add improvement | history-dependent policy adaptation is useful; the learned world-model teacher is not yet supported |
| model-guided arm beats matched recurrent belief adaptation | learned predictive scoring provides additional policy improvement |
| neither recurrent arm changes actions | the current policy interface is the primary bottleneck |
| actions change but neither recurrent arm improves behavior | action supervision, representation, or late-stage support is the primary bottleneck |

Do not describe a `belief-BC` gain by itself as evidence that controlled world
model prediction improved the policy.

# Phase III â€” Conditional architecture and data changes

Only enter the corresponding branch after Phases I and II localize the failure.

## C1 â€” If action shift is negligible: increase policy-side capacity

1. Train action-expert Q/V LoRA or equivalent narrow PEFT using the same
   Phase-I and Phase-II targets.
2. Apply matched PEFT capacity to the model-guided and direct-supervision arms.
3. Re-run the paired `N=1` comparison.
4. Only if PEFT still cannot use the belief, insert two to four projected
   belief tokens into the action-expert suffix with a zero-initialized residual
   gate.

Do not introduce belief tokens before testing the less invasive PEFT path.

## C2 â€” If actions change but model scoring is ineffective: revise the state

Build `LC-Flow v0.5` using Ï€0.5-native feature factorization:

- physical belief tokens updated from early Ï€0.5/SigLIP visual features,
  proprioception, and executed actions;
- task/progress belief tokens updated from the physical belief, late
  PaliGemma prefix features, and language;
- two physical and two task tokens initially, preserving the current total
  latent-token count;
- stop-gradient next early-visual/proprioceptive/effect targets in addition to,
  rather than only, the EMA recurrent latent target;
- policy access to both physical and task tokens.

The intended factorization is:

\[
\bar w_t=T_w(w_{t-1},a_{t-1}), \qquad
w_t=U_w(\bar w_t,V_t^{\mathrm{early}},q_t),
\]

\[
g_t=U_g(g_{t-1},w_t,H_t^{\mathrm{late}},l).
\]

Here \(w_t\) represents action-relevant physical state, while \(g_t\)
represents task-relative progress. Language need not alter physical dynamics;
it determines which physical distinctions are relevant to the task-conditioned
state and policy.

## C3 â€” If teacher support is weak: add targeted branch data

Trigger this branch when positive teachers are rare, candidate advantages are
uniformly non-positive, or selected rankings are dominated by
\(\widehat{\Delta\Phi}\) with little contribution from learned continuation
value.

- [ ] Collect 16â€“32 targeted late-chain branch sources around the unresolved
  final atom.
- [ ] Include successful, near-success, and physically distinct failed
  continuations from matched starting states.
- [ ] Split by source state/episode, not individual transitions.
- [ ] Retrain the same Phase-I model before changing architecture.
- [ ] Increase candidate support to `N=8` once only after the model has
  relevant outcome support.

More candidates cannot repair a score model that has not observed the
relevant action outcomes.
