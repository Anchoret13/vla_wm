## What the post-run audit changes

The faithful candidate graph was implemented, but four downstream contracts
were not.

### 1. The continuation labels were not sibling-paired

The registered continuation seed was described as sibling-identical, but the
implementation included `branch_index * 40`. Each candidate therefore saw a
different π0.5 flow-noise stream after its first-ten branch. Pairwise ranking,
calibration, and grounded GT labels conflate candidate effect with continuation
noise.

This is not repaired by the two-repeats-agree rule. In the stored canonical
records, `25/150` branch outcomes already disagree across their two repeats on
at least one registered outcome component.

### 2. Distinct-goal terminal success used the canonical environment goal

The distinct GoalSpec changed the language and automaton, but
`success_by_100` still called the environment's original BDDL `goal_state`.
The highest-priority element of the crossed continuation tuple was therefore
wrong for every alternative goal whose terminal predicates differ from the
canonical task.

### 3. The action × language next-semantic matrix did not enter training

`D_next.valid_bits`, `event_bits`, `flips_01`, and `flips_10` were defined but
never consumed by a loss. Their final-checkpoint parameters are bitwise equal
to seed-0 initialization. The distinct-goal pass trained `D_current` and
shared `d_obj`; the branch pass trained physical `d_q/d_obj`; immediate
GoalSpec-specific next validity, flips, and reward were absent.

Thus iteration 1 made the current latent language-sensitive, but did not fully
train the intended language-conditioned semantic transition under candidate
actions.

### 4. Dataset admission measured numerical motion, not decision support

The object replay tolerance froze to exactly zero. The chronologically first
group with any nonzero candidate-pair object difference could therefore be
accepted as `effect_resolved`.

For the `23` train accepted groups:

- median maximum candidate-pair object dispersion was `3.85 mm`;
- only `7/23` exceeded `5 mm`;
- the minimum was `0.137 mm`;
- only `1/23` had an immediate valid-bit disagreement.

The learned centered object effect was correspondingly indistinguishable from
zero on dev (`0.475 mm` model RMSE versus `0.462 mm` zero baseline;
correlation `≈.001`). `Effect_resolved` must no longer stand in for
policy-relevant counterfactual support.

### 5. The policy stage over-repeated two targets and did not cover rehearsal

Only two canonical reference-improving GT rows survived, both from staged
t4/t5 sources. In 300 updates each was reused approximately 150 times. The
sorted rehearsal bank contained 878 rows, but the same 300-step schedule
consumed only t1/t2 rows before stopping.

The resulting recurrent policy bias had substantial total amplitude but only
about two percent across-state variation. The saved action shift proves that
`W_z` can alter π0.5; it does not prove that π0.5 used a decision-specific LC
state.

Accordingly, iteration 1 neither supports nor refutes the LCWM hypothesis.

## World-model dataset contract

An imitation dataset and a world-model dataset play different roles. The new
manifest must keep those roles explicit rather than collapsing them into one
`effect_resolved` flag.

| data role | unit | what it identifies |
|---|---|---|
| nominal sequence | `(H_t, ℓ, u_t, H_{t+c})` | on-policy recurrence, posterior update, closure, nominal physics |
| action intervention | `(H_t, ℓ, {u_i,H'_{t+c,i}})` | candidate-dependent physical and semantic transition |
| crossed GoalSpec | one physical transition under every compatible `ℓ_j` | language-invariant physics and language-relative progress/reward/success |
| paired continuation | sibling branches with shared continuation randomness | causal candidate preference and continuation value |
| history contrast | matched current physical observation with distinct pasts | memory not recoverable from the current frame |
| reference-improving target | a candidate that robustly beats candidate 0 | executable policy-improvement supervision |

Every snapshot group records the following labels separately:

```text
physical_effect
task_object_effect
semantic_effect
policy_rankable
reference_improving
support_improving
history_contrast
```

Action-space distance, an arbitrary nonzero object displacement, or a
non-stock argmax is not sufficient for any of the final four labels.
