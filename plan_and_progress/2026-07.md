## 一、月度结论

7 月完成了从 frozen π0.5 基线、模拟器 snapshot/replay、批量 action sampling、feature tap，
到 recurrent latent world model、branch 数据、world-model teacher、π0.5 policy adapter 和
full-prompt `N=1` 长时域部署评估的完整研究闭环。

最重要的正结果不是某个离线 latent 指标，而是首次证明这条工程链可以真正走通：

```text
部署/分支数据
  → action-conditioned predictive model
  → model-selected action targets
  → π0.5 flow-interface post-training
  → full-prompt N=1 closed-loop rollout
```

`v0.4-e2e-v1` 在本地 Chain3 五个开发 seed 上得到 `1/5` 成功，stock 为 `0/5`；
这是项目首次完整三目标成功，但只是 existence proof，不是统计显著或 world-model 因果归因。

随后更严格的 factorial 与 public-LoHo 实验否定了对该早期结果的推广：

- 本地 75-episode factorial 中，persistent recurrent arm 没有稳定优于随机选择或 stock；
- `current-only + recurrent-WM-selected teacher` 在本地 Chain4 达到 `2/5`，但 Chain5 退化；
- specification-based public LIBERO-LoHo 上，H7/v0.5 和 v0.6 iteration-1 均未改善 stock；
- 多轮审计证明这些负结果主要否定了当时实际执行的 data/teacher/policy pipeline，
  不能直接否定“language-conditioned predictive state improves VLA”这一研究假设。

月底形成的有效研究判断是：

1. frozen π0.5 的工程接入和直接 policy conditioning 已经可用；瓶颈不是“能否改变 action”。
2. expert/on-policy demonstrations 太 stereotyped，无法识别 action-conditioned dynamics。
3. 任意非零物体位移、非 stock argmax、aggregate loss 下降都不能作为 useful WM evidence。
4. 必须用 source-disjoint、same-snapshot、replay-noise-calibrated、sibling-CRN 的干预数据。
5. candidate-dependent task/value outputs 必须只由完整的 transitioned task-conditioned latent 解码。
6. world-model ranking 与 grounded correction 是不同通道；ranking 数据为空时不应阻止 predictive-state learning。
7. 最终判据始终是 frozen/base VLA 的 full-prompt `N=1` 行为改善，并辅以 matched controls。

截至 7 月 31 日：

- 第一个 supervision-complete `v069_predictive` checkpoint 已训练完成；
- crossed action×language semantic transition 出现非零 held-out transfer；
- held-out physical branch effect 仍约等于 zero-effect baseline；
- ranking 因没有 clean train pair 被明确标为 `unsupported`，没有伪造 model teacher；
- failure-anchored acquisition 得到 17 个 clean train corrections，但只覆盖 T1/T2/T3；
- grounded `W_z` policy 在 fresh public-LoHo panel 上未胜 stock，且主要学到大而近似常数的 bias；
- carried recurrent state 相对同权重 reset state 在五个任务上都更好，但仍低于 stock。

因此 8 月入口不是换 architecture 或加 PEFT，而是补足 task/phase-balanced、reference-improving、
replay-stable 的部署数据，并让 policy coupling 真正依赖 state variation，再恢复 WM-vs-random teacher 比较。

### 07-19–07-22：feature probe、审计和 hidden-state-first 尝试

- 同帧 prompt battery 显示 canonical paraphrases 的 feature shift 仅 `0.013–0.063`，
  同场景换任务则为 `0.197–0.414`；说明 frozen backbone 有 task sensitivity 和初步 paraphrase stability。
- 早先“prompt change content-agnostic”的结论被更多 alt-task controls 推翻。
- 初版 selectivity 的 `~30×` object-role claim 后因 180°/水平镜像、off-frame disk 和 mask calibration 问题撤回。
- 校准后的 v4 只支持方向性结论：新任务目标 group 在三帧都最高，但有效 distractor 对比仅约 `0.316 vs 0.204`。
- object-position probe 的高 R² 先后暴露 static-dim variance、frame leakage、gripper/proprio confounding。
- `siglip 0.698` 的强 decodability claim 被撤回；q-only 已达 `0.641`。
- static 40/10 init-layout probe 全部未过注册门槛：SigLIP R² `0.035`，但误差 `1.71cm` 好于 q-only `1.96cm`。
- 正确结论是“存在弱 visual layout signal，但轻量 probe 未证明跨 layout cm-level extraction”，
  不是“frozen feature 没有 world information”。
- 建立 100-shard decision-rate sequential dataset；每步保存三种 feature、action block、predicate bits、terminal 等。
- Candidate-A 初版输入 sweep 中 SigLIP action sensitivity `1.06/1.10`，real-LL `0.25/0.23`，fused `0.12/0.18`；
  但 effective-rank bar `96` 被证明严重误校准，且 test split 已被用于选择。
- 审计进一步发现：present-state heads 被误当 future prediction、`a_prev` target shortcut、task intervention 只测差异、
  variance regularization 有预测代价、terminal successor 缺失、artifact config 不完整。
- v2 修复后 future predicate/proprio 与 no-vision baseline 几乎打平；原 action sensitivity 大部分来自 shortcut。
- 结论：expert demonstrations 的 task×phase×action 共线性让 assay 达到 no-vision ceiling，
  counterfactual snapshot branches 成为识别 dynamics 的必要数据。

### 07-28–07-29：首次完整 world-model-to-policy 结果

### 07-30：v0.6 faithful graph 与 iteration-1 负结果

- 固定单一 task-conditioned recurrent state：`z=U(T(z_prev,a_prev),h^language)`；
  candidate outputs 只能由 `T(z,a_candidate)` 的 transitioned latent 解码。
- 禁止 current h/z、task ID、next observation、action bypass；同一 z 同时进入 zero-init Wz policy interface。
- 机械测试覆盖 action dependency、gradient reach、no-bypass、EMA isolation、stock parity、reset=recurrent at t0、reload。
- tranche A/B 共 20 sources、30 accepted groups；训练 25 epochs，12 个 loss families 均 active。
- 但 calibrated teacher guard 因 dev ranking 仅 2 non-tied pairs且 accuracy 0，得到 `δ=.510`，因此 `0/208` model teachers。
- 三个 recurrent policy checkpoints 因生成通道为空而 bitwise identical。
- 125-episode matrix：stock `.040/.560`；GT-current `.040/.511`；三 recurrent arms `0/.528`。
- 审计随后发现 iteration-1 仍有四个关键合同错误：

  两个 GT target 被反复约 150 次且 rehearsal 未覆盖所有任务。

## 五、方法论教训

1. **结论必须随审计降级。** prompt selectivity、pose R²、rank threshold、action sensitivity、chain success、
   aggregate loss、teacher fraction都曾因新控制被撤回或缩窄；保留 chronology 比重写历史更重要。
2. **先固定问题和 baseline，再运行指标。** 从 07-20 起，实验需预注册 question、trivial baselines、pass/fail；
   不能在看到数字后重新解释注册分支。
3. **source episode 才是独立单位。** overlapping windows、sibling branches、paraphrases 和同一 source 的邻近 snapshot
   不能被当作独立样本；所有 split 和统计都按 source/group 聚合。
4. **expert demos 不能自动识别 dynamics。** task、scene、phase、proprio、action 高度共线，no-vision 或 mean-next 可达同等结果。
5. **action sensitivity 不等于 physical consequence。** target 中复制 action history、cross-batch shuffle、transition 后 readout bypass
   都能制造伪 action-conditioned signal。
6. **语言条件必须作用于完整 predictive state。** 物理 transition 加 current language readout 是 baseline；
   真正 LCWM 要转移 `z_t^language`，且 candidate head 只能看 transitioned z。
7. **same-state sibling 仍需 replay/noise calibration。** contact state restore 不完全确定；必须 repeated action、绝对 floor、
   effect/noise 比和 sibling-shared continuation randomness。
8. **CRN 是 causal ranking 的必要条件。** candidate-specific continuation seeds 会把 policy randomness 混入 action preference。
9. **GoalSpec semantics 不能依赖 canonical env termination。** distinct goal 要有自己的 terminal predicates、逐 action automaton、
   transient success 与 invalidation/damage。
10. **non-stock fraction 的 null 是 75%。** N=4 exchangeable pool 中，任何连续随机 scorer 都约 3/4 选择非 reference；
    `73–78%` positive teacher fraction 不说明模型有效。
11. **aggregate loss 很容易被 constant targets 支配。** next-state BCE、continuation failure、phase prior 都可能下降，
    同时 action-centered physical prediction变差；必须比较 zero/copy/group-mean/permutation baselines。
12. **ranking、predictive learning、grounded correction要分开。** clean rank pair 为 0 时，rank head应标为 unsupported，
    但 nominal/crossed predictive state 仍应训练；不能伪造 teacher，也不能让空 ranking 阻断整条主线。
13. **policy action shift 不是 policy improvement。** Wz 可产生很大 shift，但近似常数 bias 会伤害所有任务；
    必须报告 across-state centered variation、shuffle、task/phase variation和实际 SR/Q。
14. **同权重 reset-vs-recurrent 才能测 history。** 分别训练两个 adapter 会把 optimizer instability 混入 history contrast。
15. **行为结果不可被离线诊断无限延迟。** 每次主线 checkpoint 都应尽快进入 full-prompt `N=1`；
    但 behavior gain 后仍需 no-world、matched random、same-data model-free 等 attribution controls。

## 六、月底状态与 8 月入口

### 已完成并可复用

- frozen π0.5 baseline、evaluation、snapshot/replay、batched candidates、feature/prefix cache。
- local chain 与 public-LoHo specification-based evaluator。
- v0.6 faithful candidate path 和 no-bypass mechanical contract。
- 20-source public data lineage、135 immediate branch groups、60 corrected continuation groups。
- `v069_predictive/checkpoint_selected.pt`：首个 supervision-complete predictive LCWM。
- failure-anchored correction bank、grounded Wz checkpoint、fresh 75-episode behavior records。
- sealed `1700s` public panel仍未使用。

### 明确未完成

- 没有一个 evolving/world-model policy arm 在 public-LoHo 上稳定胜过 frozen stock。
- held-out physical alternative-action prediction仍未超过 zero-effect baseline。
- clean train ranking support仍为空；没有 calibrated model-generated teacher。
- T4/T5 没有 clean train corrections；history-contrast rows仍为 0。
- grounded Wz 主要产生 state-independent mean bias；尚未形成有用 state-conditioned control。
- 没有 sealed confirmation、LIBERO-10 retention 或 paper-level因果 claim。

### 推荐 handoff

1. 保持 v0.6 graph、frozen π0.5、Wz-first interface 不变，不先做 architecture sweep 或 PEFT。
2. 从真实 deployment/failure anchors 补齐 T4/T5 与各 phase 的 clean reference-improving corrections。
3. 提高 canonical full-prompt proposal support；support/subgoal actions只作为 provenance-labeled intervention/grounded controls。
4. 对新数据继续执行 repeated-action QC、absolute effect floor、sibling CRN、GoalSpec-specific逐 action labels。
5. 重新训练/更新 predictive model，检查 action-centered physical transfer 和 crossed semantic transition，而非只看 aggregate loss。
6. 让 policy coupling 对 z 的 state/task/phase variation敏感，避免大常数 bias；同一 checkpoint 做 reset/carry 对照。
7. grounded policy 改善 proposal distribution 后，再在独立 anchors 上 recollect；此后才恢复 calibrated WM teacher。
8. 只有 nonempty clean train ranking + independent dev calibration 时，运行 WM-selected vs exactly matched random teacher。
9. 每轮最终都回到 stock vs learned full-prompt `N=1`；成功后再开 sealed panel、retention 和 no-world/readout-only ablations。
