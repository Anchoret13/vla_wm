## Stage 4 — batched N-sampling ✅ core (plan §5)

`lcwm/sampler.py`: `prefix_forward` (one trunk pass → KV cache **and** last-layer hidden states) + `sample_chunks` (expand cache to N, batch-denoise) → `(N, 50, 7)` normalized.

- **Equivalence**: max |Δ| 0.0048 on 0.48 action scale (bf16 reduction noise) vs stock path.
- **Speed**: 16 candidates in **0.29 s** (prefix 75 ms + denoise 217 ms) vs 2.18 s sequential = **7.4×** → online-viable.
- **Diversity probe** (N=16, t0 init state): pairwise L2 ≈ 10% of chunk norm, min 0.94 (no collapse), flat across chunk (first10 0.158 / last10 0.174) → **proposals are rankable**. Formal measurement (20 states × 5 tasks + open-loop end-state dispersion via Stage-3 replay) still pending — that's what decides the σ-perturbation [DEC].

## Stage 5 — feature tap ✅ core (plan §6)

`lcwm/taps.py`: shares `prefix_forward` with the sampler (zero extra trunk cost online). h_img filtered by pad mask, optional 2×2 token pooling, pooled real-prompt `e_lang`. 153 ms/frame two-pass.
