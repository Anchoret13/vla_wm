## 月度结论

本月从“把 recurrent/latent state 接入 π0.5”逐步转向了更清晰的研究问题：

```text
部署新策略 → 收集其真实数据 → 更新 action-conditioned world model
          → 用更新后的模型改善 frozen/base VLA → 再部署、再校正
```

到月底，基础设施和大量因果消融已经齐全，但核心闭环尚未被证明。

1. **部署数据确实可以改善 frozen π0.5。** `chain1b_lr2` 上 raw-feature AWR 从 pooled base `0.458` 提升到 `0.615`，两个独立 panel 合并为 `+44/-14, p=0.00010`；state-value/AWR 变体也稳定给出 `0.531–0.562` 的增益。
2. **这些已复现的增益不能归因于 world-model dynamics。** 同数据、同 residual/AWR 框架下，去掉 transition roll、改用当前状态价值可以复现完整增益；`T_θ` 与 action-blind/no-roll 对照均未显著分开。
3. **action-conditioned dynamics 本身已经学到。** 最强 raw-latent 版本为 identity 的 `0.102×`，shuffled action 为 `0.241× identity`；早期 causal belief 版本也达到 `0.230× identity`，破坏 action 后误差约增至 `2.94×`。问题不是“模型完全没有看动作”。
4. **真正缺失的是 action 对长期 outcome 的因果支持。** `chain3` 的 72 个 exact-state 分支中，71 个状态下 8 个不同 action chunk 得到相同 outcome；next latent 虽不同，却被 π0.5 后续 replanning 拉回。
5. **单 chunk counterfactual 和 sustained policy change 是两个不同对象。** 单 chunk 干预几乎因果惰性；持续 residual policy 却能把 success 从 `0.469` 推到最高 `0.743`。后续 WM 必须学习 sustained policy/option 后果，而非独立 10-step 噪声。
6. **diverse sustained-policy data 带来首次 WM ranking 正信号，但未独立复现。** 第一组 16 policies 的 raw `ρ=0.732`、控制 scale 后 partial `ρ=0.618, p=0.0074`；第二组 raw `ρ=0.527, p=0.0192`，partial 仅 `ρ=0.256, p=0.1779`。
7. **WM ranking 尚未转化为 policy improvement。** 新 pool 中 top-1 `0.635`、bottom-1 `0.573`，top-vs-bottom `p=0.3771`；不能声称模型选择改善了 VLA。
8. **真正低成功率目标 `chain3` 仍未突破。** base `2/96=0.021`，AWR `3/96=0.031, p=1.0`；成功标签只覆盖约 `0.5%` transitions，binary outcome 无法提供足够 dense signal。

本月最准确的总判断是：

> 已证明 deployment data 可以改善 frozen VLA，也已构建可更新的 action-conditioned
> latent model；尚未证明“新数据校正 dynamics，再由 dynamics 因果性地改善 VLA”。

## 阶段时间线

### 8 月 1–3 日：V7.0/V7.1，从 oracle bridge 到真实 transition replay

#### V7.0：先验证可执行 correction 能否穿过 LC-state 接口

- 修复 strict replay 语义：`[0,0]` 才是 clean；`[+1,-1]`、`[+1,0]`、`[-1,0]`
  均为 unstable。
- correction bank 复算与预期完全一致：train `14 anchors / 8 sources`，
  `10` winning chunks / `6` positive anchors；canonical/expanded/servo headroom
  为 `0/2/6`；dev 为 `8 anchors / 5 sources`。
- 75/75 历史行为 replay 保持 success `0/0/0`；per-action 评估把 recurrent Q
  从旧的 `0.427` 修正为 `0.302`，证明 chunk-resolution 指标曾被高估。
- 两个 stored oracle 在 fresh streams 下仍为 `M=1.0/1.0`，说明局部可执行 headroom
  是真的。
- 四个 learned arms（hard/random × affine/centered）在 train-positive 上
  `M_vs_stock=0.5`、`M_vs_control=0.0`；random 与 oracle 不可分，未 promotion。
- 结论只支持：当前两目标、一个真正 discriminating target 的传输失败；
  不能外推为 LCWM–policy interface 的普遍失败。

#### V7.1：建立第一个真实 sibling-action replay substrate

- bank 阶段：26 anchors、578 decision transitions、约 6 GB raw observations。
- acquisition 阶段：5 fresh sources、14 anchors、192 transitions、约 2.4 GB。
- 合计 `770` raw rows / `40` anchors；严格去重后 `724 = 533 train + 191 dev`，
  source-disjoint，46 条 audit-only duplicate。
- 这是项目第一个真实的 `(o_t, u_{t:t+9}, o_{t+1:t+10})` bank；
  但 10-step semantic flips 为零、paraphrase 尚未 materialize、
  continuation 仅有摘要，因此不能直接宣称 language-conditioned dynamics。
- N1 action boundary smoke 在单个 T2 anchor 上通过：winner fresh pref `+1`，
  nonwinner `-1`；但后续 attribution 表明它主要学成了 state-independent bias。

#### V7.1.2：physical model、semantic tranche 和 outcome head

- preflight-noncompliant r1 的“dev objective 下降”被 trivial baseline 否定：
  latent copy floor `3e-4`，object zero-motion floor `0.122`，旧模型远差于这些基线。
- 合规 r2 中只有 LC main 的 EEF head 胜过 zero-motion：`5.38 < 7.06`；
  latent MSE `0.250` 仍约为 identity 的 1000 倍，object head 仍远差于 zero。
- 22 个 semantic windows 全部成功 crossing；17/17 natural crossings 复现，
  5/5 longer-horizon windows 发生 flip；得到 24 positive `(window, goal)` pairs。
- full LCWM `lc_full` 虽按 mixed objective 选中，但 semantic BCE 约 `0.38`
  对比 prior baseline `0.109`，goal-swap discrimination `0.4 (n=10)`，
  因而 semantic channel 记录为 unsupported。
- direct outcome scorer 在极薄 dev 上为 `6/7`，对照 readout/shuffled 为 `2/7`；
  后续更正为“candidate-ranking feasibility 的 provisional positive”，
  不是 history attribution、不是 Tail-Q、也不是 policy improvement。

#### V7.1.4/V7.2：两个重要的实现污染

- prospective selector r1 表面上 LC-vs-stock `+0.067`、vs permutation `+0.05`，
  但 null safety 失败；refresh 后 r2 为 `-0.167`、vs permutation `-0.117`。
- 随后审计发现 selector 对 candidate action **重复 normalize**、branch/continuation
  时间轴错位、fidelity 不完整、abstention aggregation 错误；
  因而 V7.1.4 的“bounded negative”被改为 **invalid/inconclusive**。
- V7.2 训练了 W0/W1/W2 和 175 个 LoHo rollouts；stock `1/25`，所有 trained arms
  `0/25`。但 policy loss 在 batch-size-1 内再次除以自身权重，完全取消了 candidate
  weights，并把 soft-FM 放大约 11–12 倍。
- 加上 full-chunk trust、stateless demo state、缺失 eval cadence、P0 mislabeled，
  V7.2C/D 最终定性为 **implementation-confounded**，不作科学负结论。

### 8 月 4–7 日：V7.3 完成一条垂直链，但 handoff 与 exposure 失效

#### V7.3B 数据

- 33 acquisition anchors、422 videos、9/10 teacher banks；replay fidelity 33/33，
  object delta 精确为 0，worst EEF `6.6e-3`。
- 125 recovery attempts 中 atomic canonical-positive 仅 2 anchors、alt-positive 5；
  privileged servo `0/59` positive。
- milestone-positive 只存在于 `t2|train`；rank-reversal 全部为空；
  pos+nonpos source quota 全部未满足。
- 第一次从 branch state 获得 terminal success：仅 `t2_s2410_d28` 两条，
  分别 113 与 155 steps；300-step horizon 暴露了 100-step horizon 的 censoring。

#### V7.3C/D/E

- gradient balance 得到 `λ_cl=1.534, λ_phys=0.0058, λ_task=1.332,
  λ_inv=84.29`；说明 unit weights 曾让 physical gradient 大约主导 `10^3–10^4`。
- task exposure 实际为 `700/725/550/425/625`，违反 task-balanced contract。
- teacher 8/9 abstain；唯一 model target 与 `u0` 的真实 outcome tuple 相同。
- policy-facing Pool(z) 几乎是 common mode：anchor pools 对 global mean 的 cosine
  约 `0.999999`，投影后的 state-specific variation 仅 common component 的
  `5e-5–1e-4`。
- scheduler 又把单个 eligible teacher anchor 重复到 300 steps，
  6 grounded anchors 各重复 30–60 次，导致 arm exposure 不匹配。
- fresh panel 125/125 rollouts：所有 arm terminal success 均为 0；
  `correction_bc`/`lc_grounded` ordered prefix 退化到 0。
- 因此终局不是“LCWM 被干净否定”，而是：
  **pooling collapse + supervision deficiency + scheduler confound** 的 bundle 失败。

### 8 月 9–15 日：V7.4/V7.5 recurrence 修复、V7.6/V7.7 acquisition instrument 审计

#### 8/15 evidence seal 与 acquisition instrument

### 8 月 22–27 日：从 noisy sibling labels 到 oracle testbed triage

  但在真正执行 acquisition rounds 前先做 oracle ceiling 检查。

#### 8/26：oracle 证明 chain1b 不是 WM bottleneck

- frozen `pi0` panel：`14/32=0.438`，13/14 successes 在最后 20 steps。
- 72 已执行 anchors 中有 36 verified corrections；用 oracle correction fine-tune 后仍为
  `14/32`，paired `+4/-4, p=1.0`，尽管 FM loss `0.181→0.066`。
- pre-pick oracle success-flip ceiling `8/72=11.1%`；post-pick ceiling `1/10=10%`。
- 结论：`chain1b@250` 主要是 trajectory-time deficit，完美 selector 也不能改善。
- `chain3@750` 为 capability wall：base `1/32`，30/32 停在 4/6 milestones；
  12 stall states 中 stock `0/12`、atomic `1/12`。
- `chain2b@500` 才满足 decision error：pooled cream-first `46/50=0.920`，
  tomato-first `0/10`，且正确行为本来就在 policy support。

#### 8/27：chain2b 上 policy improvement 成功，但 WM 因果故事被消融掉

- 64-seed baseline `51/64=0.797`；10-step atomic correction `0/4` redirect，
  40-step 为 `4/4`，确定 commitment window。
- 初版 DAgger `52/64` 不显著，且后来发现训练数据约 88% 不在 error states、
  target 还把 env-space action 当作 normalized action。
- deploy-time WM sample selector 为 `48/64=0.750`，低于 base；
  atomic-prompt shortcut 造成 held-out 1.0 假象。
- ODE/SDE 共 352 rollouts 只找到 2 个 cream mode，说明 sample argmax 无法解决。
- 在 10 个真正 error states、正确 units 上训练 corrector，head delta 提高约 157×；
  ungated whole-episode虽 8/8 redirect，却降到 `40/64`，因为破坏后续执行。
- time-bounded correction 最高 selection-set `58/64`，但 threshold 和 tap 使用 panel
  outcome 调参，且没有 matched no-gate，故正式撤回。
- fresh confirm：gated `56/64=0.875` vs fresh base `46/64=0.719`，
  `+10/-0, p=0.0020`，证明 intervention 本身复现。
- 同一 fresh panel 的 no-gate correction 为 `60/64=0.938`，
  `+16/-2, p=0.0013`，且两组 panel 都高于 gated。
- 最终因果结论：**显著增益来自 time-bounded corrective head，不来自 world model；
  gate 不必要且倾向于抑制有益 correction。**

### 8 月 28–30 日：重新对齐 latent-WM 目标，并完成 framework v2 因果拆解

#### 8/28：真正的 action-conditioned future-latent model

- v121 deployment tape：64 episodes、1,548 triples、15,970 steps；
  target 是 future PrefixVLM latent，无 reconstruction。
- on-policy T test MSE `0.3736` vs identity `0.6711`；
  action gain over no-action 的 CI `[−0.0017,+0.0089]`，说明 `u≈π(z)` 下动作不可识别。
- action-diverse deployment 后 action gain 变为显著；proprio transition 最强：
  action `0.117× identity`、no-action `0.235×`、shuffled `1.217×`。
- corrected deployment ranking 仍未胜 random；后查到 sigmoid(logit) saturation
  曾把 8 candidates 压成 1–2 个 float，相关早期 null 被标为 invalid 后重跑。
- exact candidate execution 给出真实 oracle leverage：σ=0 random `0.469`、oracle `0.688`；
  σ=3 random `0.562`、oracle `0.875`。
- 2,048 candidate labels / 256 groups（62% mixed）花 506,445 steps；
  WM ranking 相对 direct head AUC 增约 `0.024`，20 paired splits `p=0.041`。
- fresh 64 panel：base `0.391`、random branching `0.562 (p=0.043)`、WM `0.609`；
  WM-vs-random `p=0.648`，所以只证明 branching，不证明 WM。
- scope correction：frozen pooled latent、exact-next MSE、三阶段训练的早期负结果
  不能再外推到正确构造的 latent WM。
- imagination residual 在 96 fresh seeds 上灾难性下降：base `0.458`，
  imagination `0.198`，no-imagination `0.156`；transition 仍未显著优于对照。

#### 8/30：framework v2 在 chain1b 与 chain3 上的边界

- chain3 U0 whole-episode best-of-16：random `0.0039`、oracle `0.0625`；
  15/16 states 全失败，σ=3 也完全不改变 ceiling，selection use 在 target task 关闭。
- chain3 supervised failure-ordering ceiling最高仅 `0.298`；182/191 failures
  都停在 stage 4，原 task-independent `ρ≥0.35` 高于可实现 ceiling。
- binary success label 在 chain1b 可恢复约 58% ceiling，在 chain3 为 `−0.008`，
  即低成功任务没有 deployable dense progress label。
- compressed 256-d WM latent 只保留 raw-feature ordering signal 的约 31–34%；
  outcome weight 增大时甚至到 `−53%`，而 raw 2073-d features 可达 `ρ=0.417`。
- raw-conditioned AWR 在两个 panel 合并：base `0.458→0.615`，
  `+44/-14, p=0.00010`；world-model imagination pooled 为 `+25/-25, p=1.0`，
  且显著输给 AWR `p=0.00018`。
- chain3 迁移失败：base `2/96`、AWR `3/96, p=1.0`；

### 8 月 31 日（含跨至 9 月 1 日补记）：v200–v240 evolving-WM 主线

#### v200–v208：先复现 RB-VLA，再跑真正 deployment-update loop

- 修复 causal belief bug：产生 `u_t` 的 policy 不能同时把 `u_t` 当作 producing state

- 92 demos 上 BC plain `46/96`，BC+belief `36/96`；只说明 0.23% paper data scale
  下未复现，不外推论文。

  predicted-latent success AUC `0.869`，模型与 head 均非空壳。
- one-shot residual `38/96=0.396`，93% bound saturation；pessimism 仅恢复到 base，
  因 ensemble disagreement 在 base/residual 上几乎相同 `1.0826/1.0501`。
- v208 三轮都将当前 actor 的 96 episodes 加回 buffer、refit ensemble、retrain actor：
  eval `0.500→0.479→0.510`，无趋势，且每轮显著低于 model-free AWR `0.656`。

#### v209–v225：逐层去掉 dynamics，增益仍在

- counterfactual-advantage AWR 初看比 outcome AWR 高，但 96→192→288 seeds 后，
  T-vs-action-blind attribution p-value `0.1338→0.1038→0.2678`，向 null 漂移。

  predicted next `0.549`；predicted-vs-current-only `p=0.5901`，

- 终结读法：真实 gain 来自 learned state-value filtering / advantage-weighted imitation，
  不是 action-conditioned roll。

#### v226–v233：明确单 chunk 因果 ceiling

- near-neighbour action→outcome probe 为负；exact-state chain3 branching 给出决定性结果：
  72 states 中 71 个没有任何 within-state outcome variance，within/between ratio `0.018`。
- action→next latent 成立，action→task outcome 失败；π0.5 replanning 把单 chunk
  perturbation 校正掉。
- 8 个 sustained residual policies 的 deployed spread `0.25`，但旧 T imagined spread

- model-free AWR scale 0.05 在 288 seeds 达 `214/288=0.743`；
  这是当前强 baseline，不是 WM 结果。

#### v234–v240：用 diverse sustained-policy data 校正模型，正信号后未复现

- 对同六个 held-out policies，旧模型 `ρ=-0.464`，新模型 `ρ=+0.551`；
  imagined spread 从 `0.0050` 到 `0.0384`，但 n=6 exact permutation p=0.136。
- 第一组 16 policies：deployed `0.427–0.781`，raw `ρ=0.732, p=0.0008`；

- 最终结论：raw ranking 约等于“smaller residual is better”；

## 与最终目标的对齐

目标不是“训练一个预测 loss 很低的模型”，而是一个会随部署数据更新、并反过来改善
当前 VLA 的 recursive learning system。按这个目标，本月底状态如下。

| 目标环节 | 当前证据 | 状态 |
|---|---|---|
| frozen/base VLA 可安全回退 | 多个 panel 有 byte/matched baseline | 已具备 |
| 部署时记录真实 executed actions/observations | V7.1、V8 banks、v121/v124、v206/v208 | 已具备 |
| 新数据进入累计 replay | V7.1 union、v208 4→7 tapes、sustained tapes | 已具备原型 |
| WM 随新部署分布被校正 | sustained data 使 `ρ -0.464→+0.551` | 初步成立 |
| action-conditioned future-latent model | raw T `0.102× identity`，shuffle 明显恶化 | 已成立 |
| updated WM 优于 stale WM | 仅 policy-ranking 初步信号，无完整 next-round calibration | 未闭环 |
| WM 生成/选择动作优于 matched model-free | 多数实验为 null 或更差 | 未成立 |
| `π1 > π0` 且归因 dynamics | policy gain 可得，但都可由 value/AWR/corrector解释 | 未成立 |
| `π2 > π1` 的持续 evolution | v208 三轮无上升趋势 | 未成立 |
| 真正低成功率 target task 改善 | chain3 2/96→3/96 | 未成立 |
| 跨 actor seed、独立 pool 复现 | fixed setting seed variance约0.24；partial未复现 | 未成立 |

要支持核心论文 claim，后续必须同时满足：

1. `M_{r+1}` 在新策略分布的 episode-disjoint holdout 上显著优于 stale `M_r`；
2. action-shuffle/action-blind/no-roll 控制显著变差；
3. 使用 `M_{r+1}` 的 controller 优于 same-data model-free adapter；
4. evolving WM 优于 frozen one-shot WM；
5. policy improvement 在独立 actor seed 与独立 deployment panel 上复现；
6. controller 的决策对象是 sustained policy/option，而非已经测得因果惰性的单 chunk。

## 失败、修正与方法论教训

1. **先测 causal ceiling，再建模型。** v229 的 72-state exact branching 本可先说明单 chunk outcome 几乎不变。
2. **预测得准不等于预测对象有决策价值。** T 可为 `0.102× identity`，同时 action 对 outcome 在 71/72 states 无影响。
3. **新策略分布必须进入 WM 数据。** 单次 on-policy tape 只教会模型 π0.5 attractor；sustained bias 必须作为数据分布存在。
4. **actor prior 是 imagined rollout 的必要组件。** v230 缺 prior；v232 加入后排名更差，但这才是正确 closed loop。
5. **action 输入存在不等于 action-conditioned causality。** on-policy `u≈π(z)` 时 no-action 几乎等价；需要可识别 intervention distribution。
6. **component loss 要按物理意义平衡。** 2048-d hidden 曾淹没 25-d proprio；reporting 不能替代 optimisation weighting。
7. **library reduction 要在真实 graph 上测。** V7.2 scalar weights 被自身归一化取消，是本月最严重的 objective bug 之一。
8. **credit boundary 要测 suffix invariance。** 初版 V7.3 test 全 PASS 仍漏掉 candidate suffix 泄漏。
9. **budget/horizon 是 measurement instrument。** 30/60-step recovery、250-step chain1b、120-step probe 都曾由截断制造结论。
10. **reference、anchor、source failure 不是同一随机对象。** Action 2P 的 source-failure anchor 上 fresh reference 可 2/3 成功。
11. **continuation repeats 不能伪装成 candidate support。** B_boot-v2 更“丰富”只因 R=3；cross-seed noise 更大。
12. **同一 actor 换 panel 与换 actor seed 是两类复现。** 固定 config 的 seed 差可约 0.24。
13. **selection panel 不能调 threshold/timing 后再作 confirm。** chain2b 58/64 因 panel leakage 被撤回。
14. **no-gate/no-roll/action-blind 必须同步存在。** 否则无法拆开 intervention、value filter 与 dynamics。
15. **single restart 与小 n correlation 易反转。** v137、v209、v237 都要求独立 split/pool 后再 claim。
16. **centering 只能暴露已有内容。** recurrent core 若 inert，换 pooling 无法恢复 history。
17. **privileged 与 deployable labels 要分开。** `Δw`/GoalAutomaton 是仿真特权；binary success 在 chain3 极稀疏。
18. **snapshot branching 是 simulator affordance。** 真实机器人不能 reset；论文必须明确 supervision 限制。
19. **provenance 不能靠事后改 manifest 修复。** 应 content-seal、preserve-before-write，并记录永久丢失项。
20. **跨文件协作实行 one-file/one-writer。** V7.4 schedule 曾被两个 agent 覆盖，review 读到不同版本。

## 月底状态与未完成项

### 已完成

- end-to-end deployment/replay/train/evaluate 基础管线。
- 多种 future-latent、proprio、belief、raw-space dynamics 模型与严格对照。
- 真正 actor-data feedback loop 原型（v208）。
- sustained-policy data collection 与 policy-ranking pipeline。
- 单 chunk 因果 ceiling、policy ranking、selection、no-roll 等关键消融。
- 明确区分“数据改善 VLA”“state-value 改善 VLA”“dynamics 改善 VLA”。

### 月底 standing evidence

- frozen π0.5 可被 deployment data 改善，strongest no-WM baseline 为 `0.743`。
- raw action-conditioned T 是合格预测器，但 single-chunk rollout 对 improvement 无贡献。
- sustained-policy data 能扩大 imagined value spread，并产生 raw ranking correlation。
- 该 correlation 大部分由 residual scale/norm 解释；unique partial contribution 未复现。
- fresh-pool selection 尚未胜 bottom/random 的强因果对照。
- chain3 仍受 proposal support、label sparsity 和 homogeneous failure frontier 限制。

### 未完成与下一步

1. 把 evolving object 改为 **sustained controller/policy dynamics**，而非单 chunk dynamics。
2. 固化每轮 `D_r/M_r/π_r` manifest，warm-start 更新并保留旧 anchor 防遗忘。
3. 对 `M_{r-1}→M_r` 做 stale-vs-updated、new-distribution、old-distribution 三方校准。
4. 使用正确 closed-loop VLA prior 重算 policy values；禁止随机历史 action 替代 actor。
5. 先做 fixed-scale、多 actor seed 的独立 pool，解除 scale/seed confound。
6. 排名在看 deployment result 前预提交，并在完整 pool 上检验；不得只部署 top/random 子集。
7. 若 ranking 复现，再做 WM-top、scale heuristic、random、bottom、model-free value 的 matched selection。
8. 只有 WM-selected policy 在独立 panel 胜 same-data model-free，才进入 π update。
9. 完成至少两轮 `deploy→update WM→update policy`，并比较 evolving WM 与 frozen `M0`。
10. 为 chain3 引入可部署的 dense success/progress signal，或诚实承认 binary-label regime 的边界。
11. 补齐跨 actor seed、跨 model seed、跨 task 的 replication。
12. 所有新 run 记录 model/data/code hash、actor seed、tape lineage、CLI、统计 seed 和 full-precision scores。
