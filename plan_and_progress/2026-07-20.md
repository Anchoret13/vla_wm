language-conditioned predictive state on top of frozen π0.5, then use that state for
multitask sharing, long-horizon future prediction, and a better policy. Candidate
ranking is one Phase-1 policy interface; it is not the research object. This section
supersedes the initial consequence / next ordering above and is reflected in
`framework_design.md` v0.2.

### What the hidden state is

Keep the two levels distinct:

```text
H_world / H_task^τ              frozen π0.5 feature inputs
           │
           ▼
Z_t^τ  or  (W_t, G_t^τ)         learned recurrent predictive state
```

The project is not trying to declare one frozen tap to be "the world state" through a
standalone decoder. It is trying to learn `Z_t^τ = F(o_≤t, a_<t, τ)` such that:

- identical physical history + paraphrases of one task → the same predictive task
  state;
- identical physical history + different tasks → different future-relevant task
  states;
- the state changes with observation and action history, predicts multiple future
  decision steps, and does not collapse into a static task code;
- those predictions can ultimately improve policy behavior.

Therefore the frozen input source is selected by **learning behavior**: hold a small
state model and data split fixed, train it on SigLIP-only, canonical-last-layer-only,
and fused inputs, and compare multi-step prediction, intervention, shuffle, collapse,
and generalization diagnostics.

### What branch-scale candidate ranking is for

Branch data and candidate ranking are related but not identical:

```text
same simulator snapshot
  ├── action branch a¹ → future x¹ / predicates p¹
  ├── action branch a² → future x² / predicates p²
  └── action branch a³ → future x³ / predicates p³
```

The branch transitions provide controlled counterfactual action coverage. Ordinary
demonstrations contain only one executed action at each state, so a predictor may
partly ignore action and still forecast the typical next observation. Snapshot
siblings expose this failure and later provide action-conditioned dynamics targets
off the single demonstration path.

Candidate ranking is a downstream readout over those predicted futures. For an
identical physical state, action branch, and resulting physical future, changing the
task should not change shared physics; it should change which predicates, progress,
and future value matter. In the factorized hypothesis:

```text
W_{t+1}       = WorldTransition(W_t, a_t)              # task-invariant physics
G_{t+1}^τ     = TaskTransition(G_t^τ, W_{t+1}, τ)      # task-relevant future
score^τ(a_i)  = Value(G_{t+1:t+K}^{τ,i})
```

Branch-scale work consequently has three later roles: counterfactual supervision for
action-conditioned transitions, a controlled same-state task-intervention assay, and
the Phase-1 interface for reranking π0.5 proposals. It is **not** the hidden-state
definition, a prerequisite for the first LCWM training run, or sufficient evidence for
a world model. Direct-Q Candidate C is retained specifically to measure how much
ranking can be obtained without explicit latent dynamics.

### Execution decision — hidden-state-first

The standalone probe phase has completed its screening role. Except for one bounded
projection correction / selectivity rerun, it no longer gates implementation.

1. Freeze oracle `TASKID` and the provisional input matrix `{SigLIP-only,
   canonical-LL-only, fused}`.
2. Build the decision-rate sequential dataset / trainer and implement minimal
   Candidate A as the fixed instrument for the input-learning sweep.
3. Select inputs using one-to-multi-step action-conditioned prediction, action/task
   shuffles, same-history task intervention, paraphrase consistency, effective rank /
   variance, learning curves, and held-out trajectory generalization.
4. Compare monolithic A with factorized B on the top input arm(s). Do not change tap
   and state factorization in one ablation.
5. Then measure formal proposal / end-state diversity and collect a small branch set
   for counterfactual action coverage. Attach the shared value / ranking interface and
   train Candidate C on the same branch split as the no-WM control.
6. Promote A/B through learned-state evidence first and policy evidence second; the
   final Phase-1 claim remains paired closed-loop improvement over frozen π0.5.
