
## v200-v208 — RB-VLA reproduced, then the placement it enables, measured

Goal anchor (five axes). task chain1b_lr2, frozen pi0.5 at 0.469; object
T_th(b_t, E_a(u)) rolled forward under a CANDIDATE action; target the future
latent, no reconstruction anywhere; data deployment tapes; placement inside the
policy — the axis added on 2026-08-30 and the reason this arc exists.

### The reproduction that should have come first

Asked why RB-VLA had not been reproduced before conclusions were drawn from its
components, the answer was that it had not. Reproducing it found two of my own
bugs inside one session.

1. **Causality violation.** v190's belief was trained with `b_t = f(b_{t-1}, z_t,
   u_t)`, but a BC policy PRODUCES `u_t` — it cannot be an input to the state that
   produces it. Belief-conditioned BC scored **0/96** against plain BC's 46/96.
   Fixed by shifting the action stream. This does NOT invalidate U5: in the
   residual placement pi0.5 emits the chunk first, so `u_t` is legally available
   before Delta is chosen, and v163 fed the belief exactly what it trained on.

2. **The causal fix removed action-conditioning from the prediction.** With `b_t`
   restricted to `u_{t-1}`, `pred1(b_t)` forecasts `e_{t+1}` without knowing the
   action that causes it. Such a model cannot answer "what if I did u instead",
   which is all of 5.2. v205 separates them: causal belief, action-conditioned
   transition.

The reproduction also produced a reference point this project never had: a
from-scratch BC MLP on 92 demonstrations matches frozen pi0.5 (46/96 vs 45/96),
so the plain arm works and the belief arm can be attributed.

| arm, panel 7600-7695, paired | rate |
|---|---|
| pi0.5 frozen (select_action) | 45/96 = 0.469 |
| pi0.5, chunk path, Delta = 0 | 45/96 = 0.469 (+0 -0 vs above, p = 1.000) |
| BC plain (92 demos) | 46/96 = 0.479 |
| BC + belief, causal | 36/96 = 0.375 (+8 -18 vs plain, p = 0.0755) |
| pi0.5 + AWR, model-free | 63/96 = 0.656 (+25 -7 vs Delta=0, **p = 0.0021**) |
| pi0.5 + WM residual through T_th | 38/96 = 0.396 (+10 -17 vs Delta=0, p = 0.2478) |

RB-VLA's core ablation does not reproduce at 0.23% of its data scale. Stated as
that, not as a verdict on the paper.

### The model is good; its support is not

Pre-registered controls, run BEFORE the residual was trained (CLAUDE.md rule 1):

| 1-step MSE vs enc(z_{t+1}) | value | x identity |
|---|---|---|
| learned T(b_t, E_a(u_t)) | 0.00673 | **0.230** |
| identity e_t | 0.02921 | 1.000 |
| mean E[e] | 0.05863 | 2.007 |
| shuffled action | 0.01977 | 0.677 |

Destroying the candidate action costs 2.94x — the first time T_th's dependence on
the action was measured here rather than assumed. Success head AUC 0.881 on real
latents, **0.869 on PREDICTED latents**, so the actor's objective is not vacuous.

**A structural fact, from a crash.** The `--no-action` control does not merely
weaken the model: zeroing `E_a(u)` detaches the actor from the objective, so
dV/dphi is identically zero and torch raises. A transition blind to actions cannot
do policy improvement AT ALL. This is also why every belief-as-a-feature use (U5)
could never reach 5.2 — there is no T_th in that path to differentiate through.
The control was replaced by `--shuffle-action`, which keeps the gradient alive
while carrying no true information (verified: its learned and shuffled errors are
identical, 0.01045 vs 0.01042).

### Why the residual fails, and why pessimism cannot fix it

mean|Delta| = 0.0280 of a 0.03 bound = **93% saturation**, imagined value +0.1516,
deployed rate -0.073. That is model exploitation. The literature's answer is
ME-TRPO (ensemble regularises policy optimisation) and MOPO (penalise the value by
ensemble disagreement), implemented in v207 with lam = 0 recovering v205 exactly.

It cannot bite here, and the diagnostic says why: **ensemble disagreement is 1.0826
on base actions and 1.0501 on the residual's**. The ensemble does not become more
uncertain where the residual goes, so the penalty is flat and lam only lowers the
objective uniformly. Saturation moved 95% -> 94%.

### What was actually missing: the data never flowed back

Every attempt in this repo has been ONE-SHOT — fit T_th on pi0.5's tapes, train a
residual through it, deploy once. A model frozen on another policy's data cannot
stay valid where a moving actor goes, and no amount of pessimism repairs that from
inside a single fit. ME-TRPO alternates fitting and optimisation; Dreamer refits on
the current actor's own data. So does the brief, from day one: collect during
deployment, feed it back, improve.

v208 alternates: deploy the current actor on a fresh collection panel recording the
actions ACTUALLY executed, add to the buffer, refit the ensemble, retrain the
actor, evaluate on the held-out panel.

**Pre-registered reading, fixed before iteration 0.** Eval rising across iterations
AND clearing 0.656 is the first evidence a world model contributes here. Flat,
falling, or rising but under AWR says the loop does not rescue this placement and
the model-free arm remains the better use of the same deployment data. Both get
reported.

### The loop ran. Pre-registered reading: it does not rescue the placement.

Three iterations, each collecting 96 episodes of the ACTOR's own distribution on a
fresh panel and refitting the ensemble on the grown buffer (4 -> 7 tapes).

Eval across iterations: 0.500 -> 0.479 -> 0.510. Flat, no trend, every iteration
significantly below AWR. Collection rates 0.427, 0.458, 0.365 — the actor is not
improving the data either.

Two readings that do stand:

1. **Pessimism stops the harm and buys no gain.** 0.396 -> 0.479, back to base
   (+16 -15, p = 1.000). ME-TRPO/MOPO make the residual INERT here rather than
   correct, consistent with the disagreement signal being flat (1.0826 base vs
   1.0501 residual).
2. **The loop does the same.** All three iterations sit in the noise around 0.469.

**Scope.** This bounds one family: T_th as a differentiable objective for a
residual to backpropagate through, on chain1b_lr2, at 92 demonstrations. It is not
a verdict on latent world models, and nothing here is transferred to chain3 —
CLAUDE.md: do not retire a testbed because one method failed on it.

**What the data now points at.** AWR uses actions that were actually executed and
advantages that were actually observed; it never leaves the support. T_th's only
unique capability is the counterfactual — and every use of it here has been
exploited. Untested: letting T_th speak only where it is trustworthy, with
trustworthiness defined by its OWN prediction error rather than ensemble
disagreement, which was measured to carry no signal.

### v209 — take AWR's protection and T_th's counterfactual

The two facts that suggested it: AWR reaches 63/96 because it only imitates
EXECUTED actions and therefore cannot be exploited, but its advantage is the
observed outcome, which cannot say what a different action would have done; every
residual backpropagated through T_th had the opposite profile and was exploited at
94% of the bound. So query T_th only at other executed chunks:

  A(u_i) = mean_k D_k(T_k(b_k, E_a(u_i))) - mean_j mean_k D_k(T_k(b_k, E_a(u_j)))

Buffer: 480 episodes, 212 successful (pi0.5 tapes + the three v208 collection
panels). The two arms differ in exactly one term, the advantage.

| arm, panel A = 7600-7695, paired | rate |
|---|---|
| Delta = 0 base | 45/96 = 0.469 |
| AWR, outcome advantage, belief feats | 46/96 = 0.479 |
| AWR, ACTION-BLIND model advantage | 48/96 = 0.500 |
| AWR, model advantage, belief feats | 56/96 = 0.583 |
| AWR, outcome advantage, RAW feats | 63/96 = 0.656 |

**Replication, before any claim** (model vs outcome, same stack, same bound):

| | | p |
|---|---|---|
| panel A, restart 0 | +15 -5 | 0.0414 |
| panel A, restart 1 | +9 -5 | 0.4240 |
| panel B (7400-7495), restart 0 | +13 -8 | 0.3833 |
| pooled restart 0, two independent panels | +28 -13 | 0.0275 |

Rates 0.583 / 0.521 / 0.562 against 0.479 / 0.479 / 0.510 — effect +0.104, +0.042,
+0.052, mean +0.066. **The p = 0.0414 did not hold up; it was the largest of three.**

**Attribution did not resolve.** The action-blind ablation (its ensemble's
transition trained on other episodes' actions) scored 48/96 = 0.500: model vs
action-blind is +15 -7, **p = 0.1338**. Probed before deployment, that ensemble's
within-state action separation is 4.7x smaller (ratio 0.062 vs 0.291) and its
advantage is uncorrelated with the current latent's value (+0.029 vs +0.369) — but
its correlation with the observed outcome is nearly unchanged (+0.205 vs +0.229),
which is the loophole that keeps it competitive.

**What can be said.** A consistent ordering — 0.469 <= 0.479 <= 0.500 <= 0.583 <
0.656 — with a +0.05 to +0.10 effect that is not significant against base
(p = 0.0989) nor against its own refuting ablation (p = 0.1338), and that stays
below a model-free arm containing no T_th at all. No verdict. 96 seeds resolve
+/-0.10, so this is underpowered for the effect it is chasing.

**What the probe says the advantage is doing.** 512 states x 16 executed candidate
actions: within-state sd over actions 0.3384 against between-state sd 1.1616, so
most of V(s,a) is about the state (state mean correlates +0.946 with the current
latent's value) but there IS real action separation. Subtracting the state mean
leaves an advantage correlating only +0.369 with the current value — it is not a
restatement of where you already are.

Next: power, and the one combination the data points at — U5 measured belief
conditioning significantly worse than raw (p = 0.0309) and the best model-free arm
is raw-conditioned, so pair T_th's counterfactual advantage with raw conditioning.

{model, outcome} advantage x {belief, raw} conditioning, one pipeline, the same
two panels (7600-7695 and 7400-7495), the same trust region, 192 seeds per cell.

| advantage \ conditioning | belief | raw |
|---|---|---|
| observed outcome | 95/192 = 0.495 | **104/192 = 0.542** |
| T_th counterfactual | **110/192 = 0.573** | 107/192 = 0.557 |

| paired comparison | | p |
|---|---|---|
| raw conditioning: model vs outcome | +20 -17 | 0.7428 |
| belief conditioning: model vs outcome | +28 -13 | 0.0275 |
| model advantage: raw vs belief | +25 -28 | 0.7838 |
| outcome advantage: raw vs belief | +20 -11 | 0.1496 |

**A reference number is withdrawn.** The matched outcome+raw control lands at
0.542, not the 0.656 that v185's raw AWR produced. That arm is pipeline-specific
and does not reproduce here, so every comparison in this session that used 0.656
as the high-water mark was cross-pipeline and is void. The substantive difference
is the advantage DEFINITION: v185 used an R7 reward head's potential difference on
real next states; v209 uses binary episode success.

**T_th's effect is condition-specific and does not survive correction.** It appears
only under belief conditioning (p = 0.0275) and is absent under raw (p = 0.7428).
With four planned comparisons, Bonferroni puts that 0.0275 at ~0.11.

**Standing conclusion: nothing here supports a net contribution from the world
model.** Across this whole arc — residual backpropagated through T_th (0.396),
plus pessimistic ensemble (0.479), plus the deployment loop (0.500/0.479/0.510),
plus the counterfactual advantage (0.557-0.573) — no arm containing T_th is
significantly better than a matched arm without it.

**What the data does say, and it is not about world models.** The advantage
DEFINITION dominates: 0.656 (R7 potential difference) > 0.573 (T_th counterfactual)
> 0.542 (binary outcome), all inside the same AWR frame. The largest measured
effect in this arc comes from how progress is scored, not from whether a model
rolls the latent forward.

**Two mechanistic explanations I offered and my own data refuted, recorded because
the pattern matters more than the individual errors:**
1. "the +0.066 on the belief stack just compensates for belief conditioning's own
   loss" — refuted: model+raw (0.557) is not above model+belief (0.573), and the
   interaction runs the other way.
2. "an action-blind model will be inert, near base" — refuted: it scored 0.500,
   between the outcome and model arms, and its advantage still correlates +0.205
   with the observed outcome against the real model's +0.229.

### The attribution, settled at 288 seeds — negative, and cleanly so

Three independent panels: A 7600-7695, B 7400-7495, C 7500-7595. None overlaps a
fit range or any tape in the buffer.

| arm | rate | CP95 | per panel |
|---|---|---|---|
| Delta = 0 base | 135/288 = 0.469 | [0.410, 0.528] | 0.469 / 0.479 / 0.458 |
| ACTION-BLIND ablation | 152/288 = 0.528 | [0.468, 0.587] | 0.500 / 0.521 / 0.562 |
| T_th counterfactual | 162/288 = 0.562 | [0.503, 0.621] | 0.583 / 0.562 / 0.542 |

| comparison | | p |
|---|---|---|
| T_th vs base | +59 -32 | **0.0061** |
| action-blind vs base | +49 -32 | 0.0748 |
| **T_th vs action-blind** | **+38 -28** | **0.2678** |

**The attribution p-value moved monotonically AWAY from significance as power rose:
0.1338 (96) -> 0.1038 (192) -> 0.2678 (288)**, and on panel C the action-blind arm
(0.562) outscored the T_th arm (0.542). That trajectory is the signature of a null
effect that looked positive at low power. Had the p = 0.0414 at 96 seeds been
announced, this would have been the seventh withdrawal.

**The result, stated with its conditions.** A residual trained by AWR whose weights
come from a learned value function's within-state comparison across executed chunks
improves frozen pi0.5 on chain1b_lr2 from 0.469 to 0.562 (+59 -32, p = 0.0061,
288 seeds, three panels; Bonferroni over the six arms compared against this base
leaves 0.037). **The gain is NOT attributable to T_th's action-conditioning**: a
transition trained on other episodes' actions produces a statistically
indistinguishable gain (p = 0.2678). What carries the effect is the comparison
STRUCTURE plus a learned value head, not the model's dynamics.

**What would overturn it**: an arm with the same comparison structure and value
head but no transition at all - scoring candidate chunks by a head on the CURRENT
latent, no roll. That is the remaining refutation and it has not been run.

## Terminal reading for this arc, on chain1b_lr2

**A real deployment-time gain exists and replicates**: frozen pi0.5 goes from
0.469 to 0.531-0.562 across three independent panels, p between 0.0067 and 0.0474,
trained only on trajectories collected during deployment.

**It is entirely attributable to a learned STATE-VALUE filter.** An advantage of
Phi(z_t) - current state only, no next latent, no transition, no action
discrimination - reproduces the full effect. The mechanism is advantage-weighted
imitation of behaviour that occurred in high-value states. Every world-model
component was removed one at a time and none of them changed the outcome.

**What this does and does not say.** The object built here IS a latent world model
by every axis, and it passed its pre-registered controls: action-conditioned
(shuffling costs 2.35x), 0.102x identity, no reconstruction, deployment data,
inside the improvement loop. So unlike 2026-08-27 - where "the world model does not
help" was unsupported because no world model existed - the negative result here is
attributable. It bounds the USE, not the object.

**Not transferred to chain3.** This architecture has never been run on the 0.01
target task. CLAUDE.md: do not retire a testbed because one method failed on it.

### v226 — the ceiling that explains all of it, and should have run first

Zero environment cost. Pairs of transitions whose states are near-neighbours in the
VLA's own latent, from different episodes; x = the difference in their executed
chunks, y = the difference in what followed one committed chunk later. State is
held approximately fixed by construction, so only ACTION information can score.

| configuration | action diff -> outcome diff | shuffled control | net |
|---|---|---|---|
| all data, closest 50% of pairs | -0.240 | -0.079 | -0.161 |
| all data, closest 20% of pairs | -0.354 | -0.049 | -0.305 |
| sigma-perturbed tapes only | -0.221 | +0.114 | -0.335 |

Held-out correlations are negative with controls near zero: the fit is noise. And
the action diversity is real - sigma is drawn PER CHUNK in v121, so two of the four
pi0.5 tapes carry sigma in {0, 0.6, 1.5, 3.0} within episodes.

**Root cause.** On chain1b_lr2, at c = 10, the action's effect on the near-future
outcome is not learnable at a matched state. There is no counterfactual for a world
model to be right about in the direction that improves the policy - which is why
every placement collapsed to a state-value filter, and why Phi(z_t) alone
reproduces the whole gain. Not an architecture failure.

**Process failure, the most expensive of this session.** CLAUDE.md already requires
zero-cost diagnostics BEFORE candidates, and this is exactly one. It was applied to
selection in U0 and never generalised. Running it before v205 would have explained
the arc in one measurement instead of ~15 deployments.

**Caveat.** "Near-neighbour" in 2073-d is coarse - median matched distance 21.8
against a random pair's 62.3 - so the probe is a weak instrument. It is, however,
the same instrument that would have shown a strong signal.

**What it points at.** c = 10 has been fixed for the entire project. Each chunk
commits 10 environment steps, so an action's effect must survive ten steps of
dynamics before it appears in the next recorded latent. That is a contract choice,
not a physical constraint, and the diagnostic says it is a candidate for why the
ceiling is at chance.

### v229 — the definitive ceiling, and the mechanism behind every negative result

Exact-state branching on chain3_lr2, the actual target task. Deterministic replay
to a branch point, then N = 8 different candidate chunks from the SAME state
(sigma = 1.5, since pi0.5 under the ODE emits near-identical candidates), each
followed by 5 chunks of pi0.5's own control. Progress = BDDL events achieved.
24 seeds x 3 branch points = 72 states, 576 branches.

```
(a) WITHIN-STATE spread over 8 candidate actions: mean sd 0.0067
    1 of 72 states has ANY within-state variance
    BETWEEN-STATE spread of group means: sd 0.3729
    ratio within/between 0.018
```

Typical state: `s8300 b150: progress [1,1,1,1,1,1,1,1] sd=0.000`. From an identical
state, eight genuinely different action chunks produce identical outcomes in 71 of
72 cases. Question (b) - whether the difference is predictable - is moot.

**The mechanism, from two measurements together.**

| link | measured |
|---|---|
| action -> a different next latent | **holds** (shuffling the action costs T_th 2.35x) |
| action -> a different outcome | **fails** (71/72 identical, exact-state branches) |

**The world model accurately predicts a difference that does not matter.** The
quantity 5.2 asks it to predict - the consequence of ONE action chunk - is causally
inert on this task at c = 10, because pi0.5 is a strong attractor that re-plans
after the chunk and corrects the perturbation away. Not a modelling failure; the
predicted object has no downstream effect.

This is consistent with everything else measured: SUSTAINED intervention does move
the outcome (a residual applied at every chunk: 0.469 -> 0.531-0.562, p = 0.0067),
while a single-chunk counterfactual does not.

**Process failure, the largest of the session.** This costs 576 short branches and
would have run in under an hour. It bounds every world-model use in the framework
before one is built. CLAUDE.md already required zero-cost diagnostics before
candidates; it was applied to selection in U0 and never generalised to the object.

**Where this leaves the mission.** A world model that predicts single-chunk
consequences cannot help here, and that is now measured rather than inferred. What
is NOT ruled out: a model that predicts the consequence of a SUSTAINED policy
change - the thing that demonstrably does move the outcome. That is a different
predictive object from 5.2 as written, and it is the one the evidence points at.
