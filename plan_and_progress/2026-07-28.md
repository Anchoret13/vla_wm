# 2026-07-28 — First-principle correction: train the policy now

## Correction

The previous queue still treated a clean world-model contract as the object of
the project. That reverses the dependency.

The project first principle is:

> **The purpose of pi05-lcwm is to improve the VLA through a learned
> understanding of real-world dynamics.**

Its operational consequence is that learned language-conditioned dynamics
must produce a better deployed full-prompt `N=1` π0.5 policy; a cleaner model
in isolation is not the endpoint.

The representation hypothesis remains that language acts as a task identifier:
different descriptions of the same task should induce the same task-conditioned
state, while different tasks may select different predictive states over the
same visual/action history. But representation quality, crossed-language
assays, candidate ranking, and model calibration are intermediate mechanisms.
They are not allowed to become prerequisites that indefinitely delay policy
training.

A result is on the mainline only when it advances this chain:

```text
learned language-conditioned state/dynamics
        → model-generated action-learning signal
        → changed π0.5 action distribution
        → full-prompt N=1 success rate
```

If an experiment stops at latent metrics, effect prediction, ranking, or
finetuning loss, it has not yet answered the project question.

## M3 — Turn the learned model into policy targets

Use the already-built A2 replay/policy interface.

### Candidate set

- [ ] Use all **207 actionable** train late-chain 2/3 decisions. The 212
  state count includes one terminal record per source, and those five records
  have no outgoing cached action chunk.
- [ ] At each state, reconstruct the exact full-prompt π0.5 prefix/KV.
- [ ] Build one total candidate tensor `[4,50,7]` per state: index 0 is the
  cached stock chunk and indices 1–3 are newly sampled, fixed-seed chunks from
  frozen π0.5.
- [ ] Transition and score only the first ten executed/replanned actions:

  \[
  \hat Q_i
  =
  \hat r_i
  + \widehat{\Delta\Phi}_i
  + 0.99\,\hat V_{\mathrm{next},i}.
  \]

- [ ] Store candidate noise seed, first-ten block, component scores, total
  score, selected candidate, recurrent \(z_t\), and world-model checkpoint
  hash.
- [ ] Assign state IDs by sorted `(source_id, decision_index)` and derive each
  candidate seed from that stable ID; reruns must reproduce the candidate
  tensor bit-for-bit.
- [ ] Add one offline recurrent-state helper that unrolls `LCState` from the A2
  episode start to an arbitrary cached decision before scoring candidates.

Candidate ranking here is not a separate certification assay. It is how the
world model creates the action target consumed by the policy.

### Teacher rule

- [ ] Reference candidate: cached stock π0.5 chunk.
- [ ] Candidate proposal: highest-scoring non-stock candidate among indices
  1–3; it becomes a teacher only if it beats stock.
- [ ] Advantage:
  \(\hat A=\hat Q_{\mathrm{best}}-\hat Q_{\mathrm{stock}}\).
- [ ] Reuse the existing bounded weighting convention:
  `positive_advantage_weights`. Its `positive` mask is one-hot only at the
  best non-stock candidate when \(\hat A>0\), producing weight
  \(1+\operatorname{clip}(\hat A,0,1)\); every other candidate has zero
  teacher weight. Do not introduce a margin, temperature, or calibration
  sweep in this first run.
- [ ] Mask policy credit to the first ten actions.
- [ ] Reserve the **143 actionable decisions before 2/3 completion** as the
  full-50 stock rehearsal pool. This protects early soup/sauce behavior
  without assigning conflicting stock and teacher targets at the same late
  state.

The cached Chain3 stock chunks are a local stock-policy anchor, not LIBERO-10
expert-demonstration rehearsal. Do not use this first closed-loop attempt to
make a retention claim.

Do not require agreement with real branch ordering before using the teacher.
Real branches remain useful post-hoc evidence and failure localization.

**Artifact:** `results/lc_flow_v04_e2e_v1/candidate_teacher.pt` plus a manifest
containing data/code/model hashes. `scripts/test_model_teacher.py` checks total
candidate count, deterministic replay, \(V_{\mathrm{next}}\) alignment,
one-hot teacher selection, and first-ten-only model credit.

Each route returns to policy finetuning and paired `N=1` evaluation. None opens
another free-standing diagnostic program.
