## A1 design (registered)

**Phase-aware potential Φ** for the active atom (first false goal atom in
canonical order), lexicographic so no signal leaks across phases and raw
object-to-basket distance is used ONLY inside transport:

Φ = C + φ(active), where C = number of completed atoms (1.0 each; hard
no-damage: any completed atom turning false is a training-visible violation
flag, never silently re-scored), and φ ∈ [0,1):

| phase | entry condition (lexicographic, highest wins) | within-phase term | φ range |
|---|---|---|---|
| approach | default | 1 − clip(d(EEF, obj)/d_ref, 0, 1), d_ref = d at episode start | [0.0, 0.2) |
| grasp | d(EEF, obj) ≤ 0.05 m | gripper closure fraction | [0.2, 0.4) |
| lift | grasped AND obj_z ≥ z0 + 0.03 m | clip(Δz/0.10, 0, 1) | [0.4, 0.6) |
| transport | lifted AND moving | 1 − clip(dxy(obj, basket)/dxy_at_lift, 0, 1) | [0.6, 0.9) |
| placement | dxy(obj, basket) ≤ 0.08 m | descent into basket | [0.9, 1.0) |

Registered constants: near = 0.05 m (matches the contact trigger), lift
threshold 0.03 m, lift reference 0.10 m, basket radius 0.08 m; gripper
closed threshold to be calibrated on ONE train demo (task0 demo0) and then
fixed — calibration recorded here, never re-tuned per seed.

**Separate targets kept**: true one-block reward r (atom flips), phase
progress Φ/ΔΦ, composite success, environment termination, V^π0. The P5
score is registered as
Q̂_score = r̂ + λ_Φ·ΔΦ̂ + γ_decision·V̂(T(z,u)), λ_Φ = 1.0 default.

**Discount convention resolved**: γ_decision = 0.99 applied once per
ten-action decision everywhere (V targets, P5 score); the design doc's
γ^10 notation is interpreted as this single per-decision factor, not a
per-env-step discount compounded ten times.

**Exit check (registered)**: on task1 (cream-cheese/butter) demo episodes
— real pick-place arcs with labels — Φ must be non-decreasing up to each
atom completion on ≥90% of transitions, and specifically positive-ΔΦ
through grasp/lift windows where raw basket distance increases (the defect
that zeroed flow-positive coverage on 07-24). Hand-check script:
scripts/test_phase_potential.py, CPU-only on stored labels.

### A1 Amendment 1 (written before rerun): attachment replaces gripper closure

Hand-check trace (task1 demo0) falsified the registered gripper-closure
criterion: the summed gripper qpos at grasp is **object-dependent** —
soup can −0.012, butter −0.002, cream-cheese box **+0.003** — so no single
closed-threshold exists and `grasped` never fired on task1; Φ then
oscillated inside the grasp phase while the object was demonstrably being
carried (obj_z 0.446→0.731, d_eef pinned at 0.003). Replacement criterion,
object-independent and computable from stored labels: **attachment** :=
d(EEF, obj) ≤ 0.05 m AND ‖obj − obj_start‖ ≥ 0.02 m (the object has moved
with the hand). Grasp-phase progress becomes displacement fraction
clip(‖obj − obj_start‖ / 0.02); lift requires attachment + Δz ≥ 0.03 m as
before. Gripper constants stay recorded as calibration data but leave the
phase logic. Thresholds otherwise unchanged; the 90% exit condition and all
other registered terms unchanged.

`chain_episode_cache_v1` (per stock chain source episode, deterministic

  50-step chunks `[70,50,7]` (exact stock chunks via recorded noise);

  to the existing relabel sidecars at every decision** (free determinism
  regression);

  built only behind an explicit flag and never auto-loaded.

Policy interface (`lcwm/policy_interface.py`): given a cached episode +
decision index, rebuild the obs dict → `_obs_to_policy_batch` →
`prefix_forward` → PrefixCache (hidden + KV) and sample N supported
candidates with recorded seeds.
