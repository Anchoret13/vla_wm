## U0 — the oracle ceiling on the target task  `[framework §5, "run first"]`

Whole-episode best-of-N, which upper-bounds any per-step re-ranking. 16 states ×
16 rollouts on `chain3_lr2`, 191,936 env steps.

| | value |
|---|---:|
| random-pick (base) | 0.0039 |
| **oracle best-of-16** | **0.0625** |
| ceiling gain | +0.0586 |
| states with ≥1 success | **1/16** |
| deterministic (all-fail) states | 15/16 |

**Reading, per §6.2:** *no outcome variation in the proposal pool → the setting or
the proposal mechanism is wrong; say nothing about the model.*

Even a perfect scorer over 16 candidates reaches ~6%, and that figure rests on a
single successful state — CP95 on 1/16 is roughly [0.002, 0.302]. **U1 (re-ranking)
is capped on the target task**, and the cap is a property of the VLA's own sampling
distribution, not of any model.

This is the same structure found on `chain2b` (`p_cream` = 0/352), now measured on
the task the paradigm is actually aimed at. U0 cost one panel and moved U1 out of
the critical path before a scorer was built — which is what it was placed first for.
